📜 原文

天下皆知美之为美，斯恶已。皆知善之为善，斯不善已。故有无相生，难易相成，长短相较，高下相倾，音声相和，前后相随。是以圣人处无为之事，行不言之教；万物作焉而不辞，生而不有，为而不恃，功成而弗居。夫唯弗居，是以弗去。

📖 四步导读

《第 2 章》四步导读


①书概览（5 分钟，建立全貌）

本章从“天下皆知美之为美，斯恶已”切入，说明美与恶、善与不善不是孤立存在的属性，而是在相互对照中才被规定出来。接着以有无、难易、长短、高下、音声、前后六组关系，揭示一切概念都处在相生相成、相较相倾、相和相随的依存之中。由此引出圣人的处世方式：处无为之事，行不言之教，生而不有，为而不恃，功成而弗居。最重要的收获是：价值判断与概念规定具有相对性，不居功反而功不去。


②多问题意识关联

  1. 1. 如果天下人都一致认定某样东西是“美”，会发生什么？老子说“斯恶已”——美的标准一旦确立，丑就同时被对照出来了。
  2. 2. 如果“有”与“无”、“难”与“易”都只能互相依赖才成立，那我们能孤立地给其中任何一方下定义吗？
  3. 3. 如果一个人成就了功业却不去占有、不自恃、不居功，他的功绩反而不会失去——这个说法你能接受吗？

    4. ③其他作者观点碰撞

    1. 1. 维特根斯坦：概念的意义来自语言游戏中的用法与对比，而非固定本质。“美”与“恶”不是先有定义再使用，而是在区分中才获得规定——与本章“相生相成”的思路相通。
    2. 2. 福柯：话语实践通过区分正常与异常来确立标准，标准的确立同时生产出被排除者。“皆知善之为善”正是一种区分机制：善的标准越明确，不善的范畴越清晰。
    3. 3. 荀子：善是人为建构（“伪”）的结果，需要礼义师法来矫正人性。但荀子主张积极建立标准，与老子对“标举价值引发争竞”的警惕形成对照。
    4. 4. 韩非：法家强调“名”与“形”的参验，标准必须客观明确、可操作。这与老子对概念相对性的强调构成张力：一个要固定名实，一个要揭示名实的依存与流动。

      5. ④精读推荐（小白怎么读这章）


      （1）第一遍（速览）：三个关注点

      • - 美与恶、善与不善为什么“皆知”之后就出问题？“斯恶已”“斯不善已”两个“斯”字是关键。
      • - 六组对立分别用什么动词描述其关系——相生、相成、相较、相倾、相和、相随，注意每组动词的细微差异。
      • - 圣人做了哪些“不”：不辞、不有、不恃、弗居，把这些“不”列出来看它们之间的连续关系。

      （2）第二遍（细抠）：两个必看的论证

      • - “天下皆知美之为美，斯恶已”——价值判断的相对性：美不是孤立属性，其确立同时带出恶，善与不善同理。
      • - “夫唯弗居，是以弗去”——不居功反而功不去：放弃占有与保全之间有一种辩证关联，不是消极退让，而是对“占有—失去”逻辑的翻转。

      （3）第三遍（思辨）：一个该追问的开放问题

      • - “夫唯弗居，是以弗去”——这个“弗去”是对谁而言的？是客观效果上功绩被保全，还是主观上根本不挂怀得失？如果圣人根本不在意功绩去留，“弗去”还构成一个值得追求的结果吗？

      📝 结构化笔记

      章节主旨：本章处于全书立义之后的展开位置，借美恶、善不善及有无难易等对立关系的相互依存，说明价值判断与概念规定的相对性，并由此引出圣人“处无为之事，行不言之教”的处世方式，以及“生而不有、为而不恃、功成而弗居”的政治与人生原则。

      📌 核心命题

      1. 美与恶相互依存，天下皆知美之为美时恶已随之显现。
      2. 善与不善相互依存，天下皆知善之为善时不善已随之显现。
      3. 有与无、难与易、长与短、高与下、音与声、前与后都处在相生相成、相较相倾、相和相随的关系中。
      4. 圣人以无为的方式处事，以不言的方式施教。
      5. 圣人让万物兴起而不加干预，生养而不占有，作为而不自恃，功成而不居功。
      6. 正因为不居功，功绩才不会失去。

      🔑 关键论据

      1. 天下皆知美之为美，斯恶已。
      2. 皆知善之为善，斯不善已。
      3. 故有无相生，难易相成，长短相较，高下相倾，音声相和，前后相随。
      4. 是以圣人处无为之事，行不言之教；
      5. 万物作焉而不辞，生而不有，为而不恃，功成而弗居。
      6. 夫唯弗居，是以弗去。

      💡 新概念

      美之为美，斯恶已
      当天下人都知道什么是美时，丑恶也就随之被对照出来。
      善之为善，斯不善已
      当天下人都知道什么是善时，不善也就随之被对照出来。
      有无相生
      有和无不是孤立存在，而是在相互对照中生成和显现。
      难易相成
      难和易相互依存，通过彼此对照而成其为难易。
      长短相较
      长和短通过相互比较才显出各自的规定。
      高下相倾
      高和下相互依存、相互倾斜对照而成立。
      音声相和
      音和声相互应和，才形成可辨的声响关系。
      前后相随
      前和后相互跟随，在次序中彼此规定。
      无为之事
      圣人不是强行造作，而是顺应事物本身来处理事务。
      不言之教
      圣人不用言说训诫，而以自身行事来示范教化。
      生而不有
      生养万物却不把万物占为己有。
      为而不恃
      有所作为却不自恃有功、不依赖功劳自夸。
      功成而弗居
      事情成功了却不把功劳据为己有。
      弗居，是以弗去
      正因为不居功，功绩反而不会失去。

        📚 术语表（L0-L3）

        L0 一句话 / L1 教材级 / L2 学术级 / L3 哲学反思

        术语L0 一句话（普通人能懂）L1 教材级别（中文百科）L2 学术级别（引用原学术语）L3 哲学/思想史反思（不同流派怎么理解）
        美之为美，斯恶已大家都认定什么算美，丑也就跟着被比出来了。老子指出美与丑不是孤立存在的绝对标准，一旦人为标举"美"的名目，相对的"恶（丑）"便同时成立，这是价值判断的相对性与对待性。以"有无相生"式的对待关系理解价值：美之名因恶之名而立，二者"相倾"而成，非有独立自性；即后世所谓"对待之辞"。王弼以"无"为本，认为美恶之名皆由"有"所生之分别，崇本则息末；郭象则主张"独化"，谓美恶各当其分、不必统摄于一个更高的本原；庄子《齐物论》更进一步，以"天下皆知美之为美"式的分别是"成心"所致，主张"是不是，然不然"。
        善之为善，斯不善已一旦立下"善"的标准，不善的事也就同时被界定了。与"美之为美"并列，说明善恶之名相互对待而生，人为树立善的名目反而使不善凸显，老子由此警示名教标准化的局限。善不善为"相成"之名，非实体；名言成立之处即分别成立之处，属老子"正言若反"的名言批判脉络。儒家孔子讲"正名"，认为名分端正则秩序可立，与老子对名目的警惕形成对照；王弼以"无"为本，谓善名亦末；成玄英以重玄之道双遣善恶之名，主张善恶两忘而玄亦遣。
        有无相生有和无不是各管各的，是互相对照才显出来的。老子认为"有"与"无"相互依存、相互生成，不能脱离对方独立成立，是《道德经》对待范畴系列的第一条。"有无相生"即对待而成：无因有显，有因无立；王弼注以"无"为万物之本，谓"有之所始，以无为本"，将此句推向本体论。王弼"贵无"，以无为本、有为末，主张"崇本息末"；郭象反对贵无，主张"独化"，谓有无各自独化、不须以无为本；河上公则从养生解，以"有"为形、"无"为神，重在有無相养以全生；海德格尔以"无"为存在之遮蔽（das Nichts），与王弼的本体之无旨趣不同。
        难易相成难和易是比出来的，没有易就无所谓难。难与易相互依存，通过彼此对照才各自成立，属于老子列举的六对对待范畴之一。"相成"谓对待而成其规定：事之难因易而显，易因难而立；即关系性的规定而非实体属性。韩非《解老》以"理"解老，将难易归于事物的"定理"，强调因理而动、不待人为分别；王弼以无为宗，谓难易之名皆生于有为分别；陈鼓应等现代研究者将此六对句读作老子"相反相成"的辩证思维之典型表述。
        长短相较长和短要放在一起比才说得清。长与短通过比较才显出各自的规定，无比较则长短之名无从成立。"相较"即相比较而形：长短非物自身之绝对量，而是关系中的规定；可与"高下相倾"互训。庄子《齐物论》以"莛与楹、厉与西施"为"道通为一"，认为长短之别起于观察立场；王弼谓长短之名因有所"有"而起，崇本则其名自息；苏辙《老子解》以"本无长短"解之，谓分别出于人心而非物性。
        高下相倾没有低处，也说不上高处，两者互相靠着才成立。高与下相互依存、相互倾斜对照而成立，是老子对待范畴中的空间性一对。"相倾"谓相倚而形：高必因下而显，下必因高而名；倾有倚、依之义，强调对待双方的依赖关系。王弼以"无"为本，谓高下之名皆生于有所"有"；郭象以"独化"解，谓高下各安其分而无待于相因；佛学中观以缘起性空解此对待，谓高下皆待缘而有、无自性，与老子"相倾"之说可相参照。
        音声相和单音和回声要互相应和，才听得出个调子来。音与声相互应和才形成可辨的声响关系，是老子对待范畴中的听觉性一对。"相和"谓应和而成：单音为"声"，成文为"音"，二者相依以成乐；即《乐记》所谓"声成文谓之音"的对照关系。王弼注以"音声相和"明对待之理，谓和由分别而后有；河上公从养生解，以音声喻神气之和，重在调和以养身；成英以重玄解，谓音声俱空、和亦不存，双遣而后得重玄。
