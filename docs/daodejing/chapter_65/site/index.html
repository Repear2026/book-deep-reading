📜 原文

古之善为道者，非以明民，将以愚之。民之难治，以其智多。故以智治国，国之贼；不以智治国，国之福。知此两者亦稽式。常知稽式，是谓玄德。玄德深矣，远矣，与物反矣，然后乃至大顺。

📖 四步导读

《第 65 章》四步导读


①书概览（5 分钟，建立全貌）

这一章老子谈论的是“怎么治理老百姓”，但结论出人意料：好的治理者不拿聪明去启蒙民众，反而让民众保持淳朴（他叫“愚”）。因为民众智巧一多，就难管；用智巧治国是祸害，不用智巧才是福气。懂得这条法则叫“稽式”，守着它叫“玄德”，玄德深远、与万物相返，最后达到“大顺”。最有趣的收获是：老子把“愚”当成褒义词，这和我们今天的常识正好相反。

②多问题意识关联

1. 如果你是一个公司的管理者，下属个个精于算计、人人会钻空子，你会觉得好带，还是难带？
2. 如果政府把所有政策细节、利益博弈都摊开让全民精算，社会会更有序还是更撕裂？
3. 如果你自己越“想明白”就越不快乐、越难安顿，那“聪明”到底是幫你还是害你？

③其他作者观点碰撞

- 荀子：主张“化性起伪”，认为人必须靠礼义、师法、学习来改造，与老子“不以智明民”的方向相反；荀子相信教化使人变好，老子却警惕智巧使人变坏。
- 韩非：同样谈“愚”，但路线不同。韩非的“愚”是让民众无知以服从法令，属于法术之治；老子则把“愚”连到返朴与玄德，并不只是统治技术。
- 维特根斯坦：晚期认为许多困惑来自语言误用，澄清语言比堆叠理论更重要。可与老子对“智多”的警惕相参：有些“明白”只是把话说乱了。
- 福柯：对“启蒙”“治理术”有系谱学分析，指出知识、权力、规训互相缠绕。可用来反问老子：不以智明民，是否也是一种更隐蔽的治理技术？
- 卢梭：在《论人类不平等的起源》中赞美“自然状态”的淳朴，批判文明带来的算计与不平等，与老子“古之善为道者”的返朴姿态形成呼应。

④精读推荐（小白怎么读这章）

（1）第一遍（速览）：关注三个点——①“明民”与“愚之”的对比，先弄清老子说的“愚”是什么意思（不是愚蠢，而是淳朴、不机巧）；②“国之贼”与“国之福”的对举，看老子如何把“智”判成负面；③“稽式—玄德—大顺”这条递进的链条，注意它是本章的收尾结构。

>

（2）第二遍（细抠）：必须看懂两个论证——①“民之难治，以其智多”：这是老子从治理经验反推的因果论证，你要判断它是否成立，还是只是循环定义；②“知此两者亦稽式”：这里“两者”指“以智治国”与“不以智治国”两种模式，老子要求治理者同时看透两面，才算掌握“法式”，不是简单选边。

>

（3）第三遍（思辨）：该追问的开放问题是——老子说“玄德深矣，远矣，与物反矣，然后乃至大顺”，“与物反”到底指“和万物相反”还是“返回到万物本源”？如果“愚民”只是手段、返朴才是目的，那么一个现代社会的治理者，能否在不剥夺公民知情与教育的前提下，实现老子所说的“大顺”？

📝 结构化笔记

章节主旨：治国论与为道实践章。由“善为道者”如何治民切入，辨析智与愚、国之贼与国之福，提出“稽式”“玄德”“大顺”，将政治治理引向与道相合的深远境界。

📌 核心命题

  1. 善为道者不以智明民，而以愚治民。
  2. 民之难治在于智多。
  3. 以智治国是国之贼，不以智治国是国之福。
  4. 常知稽式是谓玄德，玄德深远与物反，然后乃至大顺。

🔑 关键论据

  1. 古之善为道者，非以明民，将以愚之。
  2. 民之难治，以其智多。
  3. 故以智治国，国之贼；不以智治国，国之福。
  4. 知此两者亦稽式。
  5. 常知稽式，是谓玄德。
  6. 玄德深矣，远矣，与物反矣，然后乃至大顺。

💡 新概念

稽式
治理国家需要知晓和遵循的法式或准则。
玄德
深远而与万物相返的德行。
大顺
与道相合而达到的顺遂境界。

    📚 术语表（L0-L3）

    L0 一句话 / L1 教材级 / L2 学术级 / L3 哲学反思

    术语L0 一句话（普通人能懂）L1 教材级别（中文百科）L2 学术级别（引用原学术语）L3 哲学/思想史反思（不同流派怎么理解）
    稽式治理国家得有一套明确的规矩和标准，心里有数才能办事。"稽"为考察、稽考，"式"为法式、准则。"稽式"指治国所应知晓并遵循的法度与准则，是本章"以正治国"的认识论前提。本章"能知稽式，是谓玄德"中，"稽式"被提升为体道者所把握的治道范式；其义近于"稽式"与"楷式"的古音通假，河上公本、王弼本有"稽式""楷式"异文，指可法的准则，而非外在刑法。王弼以"贵无"解此章，认为稽式非外在条律，而是"以无为本"的自然之理，知此则"玄德"自成；河上公从治身角度解"稽式"为"治身之法式"，强调守一养神；法家韩非则在《解老》中把"稽式"读作可操作的法度，与"理"相通，倾向客观化、制度化理解；陈鼓应认为此处"稽式"即"原则、法式"，是老子"正治"与"奇用兵"之间的分界点。
    玄德一种深远幽隐、不张扬却真正起作用的好德行。"玄"为幽深难测，"德"为得道之性。"玄德"指深远不显、与万物相反而相成的德行，本章与"稽式"相连，又在第10章"生之畜之"、第51章"生而不有"处复现。王弼注："玄德深矣远矣，与物反矣，然后乃至大顺"，强调玄德以"反"为用，即不由显性作为而返回本根；"反"兼有"相反"与"返回"双训，构成老子德论中"反者道之动"的实践环节。王弼以"无"释玄德，认为它是道体在治术上的自然流露，非有意为德；河上公以养生解，谓玄德为"守道深微"的内修之得，重在精气；郭象注《庄》主"独化"，反对有一个更高的德源，可推知他对玄德的理解会落在"各任其性"而非"反本"；成玄英重玄学以双遣双非解"玄"，把玄德推向"非有非无"的层次；苏辙以佛理解老，视玄德为"无得之得"；现代学者刘笑敢以"人文自然"为线索，认为玄德体现老子"无为而无不为"的价值取向。
    大顺与大道一致之后达到的那种通达顺畅、无阻无碍的局面。"大"为极致之称，"顺"为顺遂、不逆。"大顺"是玄德"与物反"之后所达到的最终境界，本章指治国者体道而行、天下自然归顺的政治理想状态。王弼注以"与物反"为前提，"反"而后"至大顺"，故大顺非顺俗，而是逆俗返本之后的"大通"；此与《庄子·天地》"不同同之之谓大"、郭象"各安其分则大顺"义可互参。王弼以"反本"为大顺，强调必须经由对世俗价值的逆转才能达成真正的顺；郭象则主张"大顺"即万物各任其性、各安其分，无需返本，是对老子"反"义的改造；河上公从身国同构出发，把大顺解为"精气不逆、百脉皆通"的养生状态；王夫之以气化解老，认为大顺是阴阳气化自然成理，非有主宰；现代学者陈鼓应认为"大顺"是老子"无为而治"的最高政治效果，与儒家"大同"、法家"治强"构成不同的理想类型。
