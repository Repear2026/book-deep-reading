📜 原文

天下皆谓我道大，似不肖。夫唯大，故似不肖。若肖，久矣其细也夫！我有三宝，持而保之。一曰慈，二曰俭，三曰不敢为天下先。慈故能勇；俭故能广；不敢为天下先，故能成器长。今舍慈且勇，舍俭且广，舍后且先，死矣！夫慈以战则胜，以守则固。天将救之，以慈卫之。

📖 四步导读

《第 67 章》四步导读


①书概览（5 分钟，建立全貌）

这一章老子先说自己讲的“道”太大，大到不像任何具体东西——正因不像，才成其大；一旦像某个具体事物，它早就变小了。接着他亮出立身处世的三件法宝：慈、俭、不敢为天下先。慈让人敢担当，俭让人能宽裕，不抢先反而成为众人的领头。反过来，舍慈求勇、舍俭求广、舍后求先，就是死路。最重要收获：真正的强大来自收敛与慈爱，而不是逞强争先。

②多问题意识关联

1. 如果你处处争第一、抢在别人前头，你会得到尊重，还是被众人提防？
2. 如果一个人对别人毫无慈爱却异常勇猛，这种“勇”最终会指向谁？
3. 如果你把资源全用来扩张、不留余地，遇到风浪时你还撑得住吗？

③其他作者观点碰撞

- 荀子：主张“隆礼重法”，认为秩序靠外在规范与教化，而非仅靠慈俭自律；可对比老子“三宝”是内在持守还是不足以为治。
- 韩非：以“法、术、势”治国，强调制度与权位，会质疑“不敢为先”在竞争格局中是否等于拱手让人。
- 罗素：在《社会改造原理》等著作中谈“创造性冲动”优于“占有性冲动”，与老子“俭”“不先”对占有欲的节制可相互印证。
- 福柯：揭示“争先”“勇猛”背后常有权力的规训与话语生产，可反衬老子三宝是对权力逻辑的主动退让。

④精读推荐（小白怎么读这章）

（1）第一遍（速览）：关注三个点——①“道大似不肖”这个悖论式表述；②三宝的具体名目（慈、俭、不敢为天下先）及其各自带来的效果（勇、广、成器长）；③结尾“以战则胜，以守则固”把三宝落到实际功用上。
（2）第二遍（细抠）：必看两处论证——①“夫唯大，故似不肖。若肖，久矣其细也夫！”体会“大”与“像某物”之间的张力；②“今舍慈且勇，舍俭且广，舍后且先，死矣！”看老子如何用三组“舍……且……”构成反面推演，说明失去根据的勇、广、先为何是死路。
（3）第三遍（思辨）：值得追问的开放问题是——“不敢为天下先”在竞争激烈的现实处境中，究竟是智慧的自保与成全，还是可能被利用的退让？慈与勇之间的“因”关系，是心理上的（慈爱使人无畏）还是伦理上的（慈赋予勇以正当性）？

📝 结构化笔记

章节主旨：本章从“道大似不肖”引出治理与处世的三条根本原则——慈、俭、不敢为天下先，并说明三者分别带来勇、广、成器长；舍弃三宝而求勇、广、先则走向死路。

📌 核心命题

  1. 道因广大而不像任何具体事物。
  2. 若道像具体事物，早就显得细小了。
  3. 应持守慈、俭、不敢为天下先这三宝。
  4. 慈能使人勇，俭能使人广，不敢为天下先能使人成为器长。
  5. 舍弃慈、俭、后而求勇、广、先，是死路。
  6. 慈用于战则胜，用于守则固，天将以慈护卫。

    道大道大到没法拿任何一个具体东西去比它。老子认为"道"是宇宙的本原与总规律，其外延无限、内涵不落形器，故称"大"。《老子》第二十五章"强为之名曰大"，第六十七章承此而言"天下皆谓我道大，似不肖"。"大"非空间量度，而是"不可名言、不可对象化"的表述：《老子》"强为之容""强为之名"，以"大"为不得已的权称。陈鼓应指出"大"在《老子》中兼有本原义与形容义，此处偏于形容道的无限性。王弼以"无"释道，认为道"无状无象，无声无响"，正因其无名无象才可称大；河上公则从养生与治身角度解"大"为道之包容覆育，落点在保身治国。海德格尔论"存在"不可被存在者化地把握，与老子"道大而不肖"有结构上的相似，但海氏是追问存在之意义，老子则直指生成之本，二者不可混同。
    似不肖正因为太大，反倒看不出它像什么。"肖"即像、类似。"似不肖"指道与任何具体器物、形象都不相似；若有相似，则道将被限定为某物而失其大。原文"夫唯大，故似不肖。若肖，久矣其细也夫"——构成一个反证式论证：可被类比者必有限，有限则"细"。此为《老子》"正言若反"的表述策略。王弼注谓"肖则失其所以为大"，强调名言规定即是对道的减损；郭象注《庄》主张"独化"，反对以任何普遍者统摄万物，其思路可用于解释"不肖"即拒绝被归入任何一类。维特根斯坦论语言界限——凡不可言说者须沉默——与此可作对照：老子并非否认道，而是指出言说在此失效，只能"强为之容"。
    三宝老子给出的三条持守原则：慈、俭、不敢为天下先。第六十七章"我有三宝，持而保之：一曰慈，二曰俭，三曰不敢为天下先"。"宝"意为所珍视、所持守的根本准则，是老子自述的实践总纲。三宝可视作《老子》由"道论"向"德论"、由形上向工夫的转轴：慈对应"生而不有"的仁厚，俭对应"少私寡欲"，不敢为先对应"后其身而身先""不争"。刘笑敢指出这类表述体现《老子》"正言若反"与"以退为进"的辩证方法论。河上公以治身治国双解三宝，重"慈"为爱民全身、"俭"为节用却奢；王弼则从"崇本息末"立论，三宝皆是"守母"以存子。儒家可对观：孔子言"仁"、孟子言"不忍人之心"，与"慈"有交叠，但儒家之仁落在礼乐人伦的建构上，老子之慈则以"不争""无为"为底色。韩非《解老》《喻老》把慈、俭读作治国之术与"重积德"的条件，带有法家化改造。
    慈以慈爱之心待人处事。"慈"在《老子》中指以柔爱、宽容、不伤害的态度对待万物与众人，是"俭"与"不敢为先"的情感与伦理基础。原文"慈故能勇"。慈不是儒家意义上的差等之爱，而是"无弃人、无弃物"（第二十七章）的普遍包容。其效果是"能勇"——慈爱反而生出真正的勇气，因所护者非己身之私。河上公以"慈"为"爱百姓若赤子"，落点在治身与治民；王弼以慈为"以柔御刚"之本。苏辙《老子解》以佛老互释，谓慈近于"无缘之慈"，与佛家"慈悲"相摄。葛兆光指出道教在后世将"慈"仪式化、功德化，与《老子》原本的政治伦理含义已有距离。
    俭节制俭省，不奢侈放纵。"俭"即节用、寡欲、不耗散。原文"俭故能广"——因不奢费，反能有余而广。与《老子》"少私寡欲""去甚去奢去泰"（第二十九章）一脉。俭在《老子》中既是治国的经济伦理（"民之饥，以其上食税之多"），也是养生的工夫论（收敛精气、不妄耗）。其逻辑是"啬"（第五十九章"治人事天莫若啬"）的延伸。河上公从养生解，以俭为"赋敛有节""不妄耗精气"；王弼以俭为"不役于物"、返本之要。韩非《解老》以"俭"论"重积德"与国家财用，法家化为理财之术。现代研究如陈鼓应强调俭的政治批判面——针对当时统治者的奢靡暴敛，而非单纯的个人修养。
    不敢为天下先不抢先、不争着做天下第一。原文"不敢为天下先，故能成器长"。指不以己意率先发动、不争居人先，与第六十六章"欲先民，必以身后之"、第七章"后其身而身先"同调。此语是《老子》"不争"哲学的政治表达：不为先，反而"成器长"（为众器之长）。其结构是"反者道之动"的具体运用，属"以退为进、以柔弱胜刚强"的方法论。王弼以"不争"为"顺物之性"，谓先则争起、后则物归；郭象主"各安其分"，反对有意标举"后"亦为造作，可能在此与老子有微异。苏辙以"不敢为先"通于佛家"无我"。韩非《解老》则把它读作君主御臣之术——不先发其意，以观臣下之实，是法家的"术"化解读。
    成器长因此能成为众器物的首长或领导者。"器"指具体器物，喻众人、百官、万事；"长"为首长、领导者。原文"不敢为天下先，故能成器长"，谓因不争居先，反被推为众物之长。此处"器"与"道"形成对照：道"朴散则为器"（第二十八章），圣人守朴不争，故能为器之长而不沦为器。这是《老子》"守母存子""无为而无不为"的结构。王弼以"不为器之首而器自归之"解，落在"崇本"；河上公以治国言，谓"能为天下长"是因谦下爱民。儒家可对观：孟子言"得道者多助"，其君长地位由德与民心而成，与老子"不争而成长"路径不同——儒家重教化与礼制建构，老子重退让与不争。
    以慈卫之天用慈爱来护卫它。原文"天将救之，以慈卫之"。谓持守慈道者，天必救之、护之。注意"天"在《老子》中多是自然、法则性的天，而非人格神。"卫"为护卫、屏障。此句把"慈"由伦理德目提升为具有存有论效力的原则：慈不仅是应然，也是"天"之所佑的实然条件。与"天道无亲，常与善人"（第七十九章）同构。河上公将此"天"人格化、报应化，谓"天佑善人"，带有汉代天人感应色彩；王弼则淡化神意，以"自然"解天，"慈卫"即"顺自然者不伤"。苏辙以佛家因果会通。现代学者如刘笑敢提醒：老子之"天"多在自然义与神性义之间滑动，不宜过度人格化，也不宜全然祛魅。

    L3王弼以"无"释道，认为道"无状无象，无声无响"，正因其无名无象才可称大；河上公则从养生与治身角度解"大"为道之包容覆育，落点在保身治国。海德格尔论"存在"不可被存在者化地把握，与老子"道大而不肖"有结构上的相似，但海氏是追问存在之意义，老子则直指生成之本，二者不可混同。

## [第 67 章]

天下皆谓我道大，似不肖。夫唯大，故似不肖。若肖，久矣其细也夫！我有三宝，持而保之。一曰慈，二曰俭，三曰不敢为天下先。慈故能勇；俭故能广；不敢为天下先，故能成器长。今舍慈且勇，舍俭且广，舍后且先，死矣！夫慈以战则胜，以守则固。天将救之，以慈卫之。
