《道德经》

老子 著 · 老子五千言 · 第 3 章
“”

📜 原文

不尚贤，使民不争；不贵难得之货，使民不为盗；不见可欲，使民心不乱。是以圣人之治，虚其心，实其腹，弱其志，强其骨。常使民无知无欲。使夫智者不敢为也。为无为，则无不治。

📖 四步导读

《第 3 章》四步导读


①书概览（5 分钟，建立全貌）

本章讲“圣人之治”的具体原则：用不尚贤、不贵难得之货、不见可欲来消解争、盗、乱；再用虚其心、实其腹、弱其志、强其骨，以及使民无知无欲、使智者不敢为，最后落到“为无为，则无不治”。有趣之处在于，它把治理重点放在减少引发争、盗、乱的源头，而不是只靠外在强制；最重要收获是理解“为无为”与“无不治”的治理链条。

②多问题意识关联

  • - 如果不尚贤真能让人不争，那么社会还要不要树立贤能榜样？
  • - 如果不贵难得之货能让人不为盗，那么欲望是被货物引发的，还是被价值排序引发的？
  • - 如果为无为就能无不治，那么“使民无知无欲”在治理中到底起什么作用？

③其他作者观点碰撞

  • - 荀子：会追问“不尚贤”是否削弱治理对贤能的依赖；他通常更强调尚贤使能。
  • - 韩非：会追问“使智者不敢为”靠什么实现；法家更关心明法、赏罚与制度约束。
  • - 福柯：会追问“不见可欲”“无知无欲”是否也是一种塑造人的治理技术，而不仅是消解乱源。
  • - 王阳明：会追问“无知无欲”是否应通过良知自觉来实现，而非仅由外部使民众处于无“知”无“欲”状态。

④精读推荐（小白怎么读这章）

（1）第一遍（速览）：关注三组“不……使……”——不尚贤使民不争、不贵难得之货使民不为盗、不见可欲使民心不乱；关注“虚其心、实其腹、弱其志、强其骨”四句；关注“为无为，则无不治”的结论位置。


（2）第二遍（细抠）：必看第一条论证链，即“不尚贤/不贵难得之货/不见可欲”如何分别对应“不争/不为盗/心不乱”；必看第二条治理链，即“虚其心、实其腹、弱其志、强其骨”如何通向“常使民无知无欲”“使智者不敢为”，再到“为无为”。


（3）第三遍（思辨）：追问一个开放问题：如果“无不治”要通过“使民无知无欲”和“使智者不敢为”来实现，那么“为无为”究竟是不刻意作为，还是以特定方式安排治理条件？

📝 结构化笔记

章节主旨：本章阐述圣人之治的具体原则：通过不尚贤、不贵难得之货、不见可欲来消解争、盗、乱，并以虚其心、实其腹、弱其志、强其骨，以及使民无知无欲、使智者不敢为、为无为，达成无不治。

📌 核心命题

  1. 不尚贤可以使民不争。
  2. 不贵难得之货可以使民不为盗。
  3. 不见可欲可以使民心不乱。
  4. 圣人之治包括虚其心、实其腹、弱其志、强其骨。
  5. 常使民无知无欲，并使智者不敢为。
  6. 为无为，则无不治。

❓ 我的错题本

    📚 术语表（L0-L3）

    L0 一句话 / L1 教材级 / L2 学术级 / L3 哲学反思

    术语L0 一句话（普通人能懂）L1 教材级别（中文百科）L2 学术级别（引用原学术语）L3 哲学/思想史反思（不同流派怎么理解）
    尚贤就是抬举能人、把有本事的人捧到高位。崇尚贤能，是先秦诸子（尤其墨家）大力主张的政治原则；《老子》第三章把它与“不争”对举，主张“不尚贤，使民不争”，认为标举贤名会诱发争竞。帛书与王弼本作“不尚贤，使民不争”。河上公注以“贤”为“世俗之贤”，谓“不贵之”则民不争；王弼则从“贵无”立说，以为“尚贤”是“有”之造作，唯“不尚”方能“使民不争”。墨家《尚同》《尚贤》以“尚贤”为治道之本，主张“虽在农与工肆之人，有能则举之”，与老子恰成对立；韩非《二柄》则把“贤”收编于法度，认为“尚贤”须以“法”为准绳，否则“贤”将成私党之资；王夫之《老子衍》以气化日新立论，谓“贤”名起于争之既生，非先有贤而后有争。
    难得之货就是稀罕、难弄到手的东西，比如限量款、稀世珍宝。指难以获得的货物。《老子》第三章以“不贵难得之货，使民不为盗”与“不尚贤”并列，把稀缺物的价值标举视为盗贼之源。王弼注：“难得之货，塞人正路，故令人行妨。”以“贵”为心之所系，贵之则争；河上公注则从“养生”角度解为“财货难得，使人贪欲”，强调对身心的戕害。郭象注《庄子》以“独化”立说，反对有一“贵”者悬于物上，认为货之“难得”本无自性，贵之者人耳；苏辙《老子解》以“无心”释之，谓“不贵”非贱货，乃不以其为贵；佛学中观以缘起性空解“难得”，谓货无自性，贵贱皆分别假立；陈鼓应指出此章“不贵难得之货”是针对当时贵族“多藏”而发，具有具体的政治批判指向。
    可欲就是那些一眼看去就让人想要的东西。指可引发欲望的事物。《老子》第三章“不见可欲，使民心不乱”，主张君主不以可欲之物示人，以免民心散乱。王弼注：“不见可欲，使心不乱。”以“可欲”为“有”之诱，心随境转；河上公注：“可欲，谓邪淫声色之事”，从养生保精立说；成玄英以重玄双遣解之，谓“可欲”与“不欲”俱遣，方为“不见”。孟子以“可欲之谓善”（《尽心下》），把“可欲”正面化，视为善端之发，与老子恰成反向；荀子《性恶》以“目好色、耳好声”为性之自然，主张“化性起伪”而非“不见”；海德格尔论“现身情态”中“欲”为先于反思的存在方式，与老子“不见可欲”的治理术路径不同；刘笑敢指出老子此说属“工具性”而非“禁欲主义”，其目标是“使民心不乱”而非灭欲。
    无知无欲让老百姓不去耍心眼、不生贪念，安安分分。使民众处于文本所说的无“知”无“欲”状态。《老子》第三章“常使民无知无欲”，与“虚其心，实其腹，弱其志，强其骨”相承，是“为无为”的具体施政。王弼注：“无知无欲，则无不治。”以“无”为本，谓“知”“欲”皆“有”之枝蔓；河上公注则解“无知”为“不妄求知”，“无欲”为“不妄求欲”，偏于养生保真；苏辙以“无心”释之，谓非绝知绝欲，乃不“以知自矜、以欲自累”。庄子《齐物论》以“大知闲闲”破“小知间间”，其“无知”是认识论上的“去成心”，与老子政治治理术不同；郭象以“独化”解“无知”，谓“知”本自足，不假外求；禅宗以“无心”为宗，马祖道一“平常心是道”，与老子“无知无欲”形似而旨异（一为解脱，一为治民）；葛兆光指出老子“无知无欲”常被后世读作“愚民”，但先秦语境中“知”多指机巧智谋，非今日“知识”义，须区分。
    无为不是躺平，而是不硬来、不瞎折腾，顺其自然地做事。以不刻意作为的方式去作为。《老子》第三章“为无为，则无不治”，是“无为”作为治道的首次正面表述，与“不尚贤”“不贵难得之货”“不见可欲”构成一体。王弼注：“为无为，则无不治。”以“无”为本，谓“为”生于“有”，“无为”乃“顺自然”而非“不为”；河上公注：“为无为，不造作也”，从养生保真立说；成玄英以重玄双遣，谓“为”与“无为”俱遣，方为“真无为”；苏辙以“无心而应”释之。庄子《逍遥游》《应帝王》以“无己”“无功”“无名”发挥“无为”，归于个体逍遥；韩非《解老》《喻老》以“术”释“无为”，谓君主“虚静无为”而臣下“有为”，是法家的君人南面之术；郭象以“独化”释“无为”，谓万物“自为”即“无为”，反对有一“为”者在其上；海德格尔以“泰然任之”（Gelassenheit）与老子“无为”相较，但一为存在之思，一为治道；陈鼓应、楼宇烈均指出“无为”非“不为”，乃“不妄为”，是“顺自然”的实践智慧。
