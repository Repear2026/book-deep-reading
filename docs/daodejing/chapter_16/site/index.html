📜 原文

致虚极，守静笃。万物并作，吾以观复。夫物芸芸，各复归其根。归根曰静，是曰复命。复命曰常，知常曰明。不知常，妄作凶。知常容，容乃公，公乃王，王乃天，天乃道，道乃久，没身不殆。

📖 四步导读

《第 16 章》四步导读


①书概览（5 分钟，建立全貌）


这一章是老子修身哲学的总纲。核心只有一条：把心清空到极致、把静守到笃定，你才能看见万物纷纭变化背后那个“各复归其根”的节奏。回到根叫“静”，叫“复命”，叫“常”；知道这个“常”才叫“明”。不知常而乱来，凶；知常，则能容、能公、能王、能天、能道、能久。最重要收获：老子把“静”从一种心理状态提升为一种认识方法——不是叫你躺平，是叫你先静到能看见规律，再按规律行动。


②多问题意识关联


如果你每天被信息流推着走，从不停下来“归根”反思，你凭什么判断自己是在“明”还是在“妄作”？

>

如果你总是急着行动、急着表态，却从没看清事物循环往复的节奏，你的“努力”会不会恰恰是招凶的“妄作”？

>

如果“知常”真能让你容、公、王、天、道、久，那“不知常”的人到底在损失什么——是机会，还是整个与世界的合拍？

③其他作者观点碰撞


  • - 荀子：也讲“虚壹而静”，但他要的是“解蔽”——把心从偏见中解放出来去认识客观之道。老子更强调“守静”作为回归本根的工夫，荀子则更重“虚”的认识论功能，两者对“静”的用法同词不同调。
  • - 王阳明：早年教人“静坐”，后来指出“只静坐也不济事”，必须“事上磨练”。这与老子“守静笃”形成张力：王阳明认为静中得的东西必须在动中验证，老子则相信静观本身就能通达“常”。
  • - 海德格尔：对“无”的追问和对技术“妄作”的批判，与老子“致虚极”和“不知常，妄作凶”遥相呼应——两者都认为现代人的问题不在做得太少，而在做得太急、太不由分说。
  • - 斯多葛派（如马可·奥勒留）：宇宙万物循环往复、各归本源，人应顺应整体秩序。这与“万物并作，吾以观复”几乎同构，但斯多葛更倾向于理性认知宇宙逻各斯，老子则更强调“静”中去体会。

④精读推荐（小白怎么读这章）


（1）第一遍（速览）：先抓三个关注点——① “虚”和“静”到底是手段还是目的？② “归根—静—复命—常—明”这条词链怎么一环扣一环？③ 最后那句“知常容，容乃公……道乃久”为什么能一路推到底？


（2）第二遍（细抠）：两个必看论证——① “万物并作，吾以观复”到“各复归其根”：老子凭什么从“看见万物生长”推出“万物都要归根”？这个“观”是感官观察还是心观？② “不知常，妄作凶”与“知常容，容乃公”构成正反两扇门：为什么“不知常”的后果不是“失败”而是“凶”，而“知常”的第一站是“容”而不是“得”？


（3）第三遍（思辨）：一个该追问的开放问题——老子的“观复”预设了万物有一个统一的、循环的“常”。如果世界本质上是开放的、非循环的、充满断裂的，“致虚守静”还能让你看到什么？或者，恰恰因为在变动不居中“静”下来，你看到的是“无常之常”——那“知常”还成立吗？

📝 结构化笔记

章节主旨：本章集中阐述修身观复与知常明道的路径：由致虚守静观察万物归根复命，进而把握恒常；并说明知常则能容、公、王、天、道、久，不知常而妄作则凶。

📌 核心命题

  1. 人应当使心虚静到极点，并笃守宁静。
  2. 万物虽然纷繁并作，最终各自复归其根。
  3. 归根称为静，也称为复命；复命称为常，知常称为明。
  4. 不知常而妄作，会招致凶险。
  5. 知常能容，容能公，公能王，王能天，天能道，道能久，终身不殆。

❓ 我的错题本

    📚 术语表（L0-L3）

    L0 一句话 / L1 教材级 / L2 学术级 / L3 哲学反思

    术语L0 一句话（普通人能懂）L1 教材级别（中文百科）L2 学术级别（引用原学术语）L3 哲学/思想史反思（不同流派怎么理解）
    致虚极把心里的杂念清空到极点，像把屋子彻底腾空。语出《老子》第十六章"致虚极，守静笃"。指主体通过消解欲望、成见与纷扰，使心灵达到极度的空明虚静状态，为下文"观复"提供认识论前提。"虚"非空无所有，而是"虚其心"（三章）意义上的去执状态；"极"为至、究竟。与"守静笃"构成对文：虚言其体之通，静言其用之定。河上公注以"除情去欲，五藏空虚"释之，走养生炼形一路；王弼则以"虚"通"无"，谓"以虚静观其反复"，把虚静提升为本体论式的观照方式；郭象注《庄》却反对"虚"为待造之境界，主张任物自尔即是虚。
    守静笃守住安静，守得牢牢的，不动摇。与"致虚极"并列，指坚定持守宁静。"笃"为厚、实、坚定之意，强调持守之力度与持久性，非一时的安静。"静"在老学中与"躁"相对（二十六章"静为躁君"）；"笃"训厚、固。此处静不是静止不动，而是不被外物牵动的定力，是"观复"得以可能的主体条件。河上公从治身解为"守静笃厚"，与爱精养神相联；王弼从"归根曰静"立说，以静为万物之常然；苏辙《老子解》则以"寂然不动"释静，明显带入佛教止观色彩，可见注家传统本身在跨系统对话中不断重构。
    观复看万物转了一圈又回到原处。指以虚静之心观照万物的循环往复。"复"即返回、回复。此"观"非感官之观，而是虚静之心的洞察。"观"在老子中有特定用法（一章"以观其妙"），非感知而是体道之观；"复"呼应"反者道之动"（四十章），构成循环宇宙论的枢纽概念。王弼以"观其反复"解，强调观者自身须先虚静，带有"以无观有"的本体论结构；陈鼓应认为此章是老子由宇宙论转向人生论的关节，"观复"是体认规律而非神秘直觉；刘笑敢则强调老子"复"的观念与"返"共同构成其"正反合"式的辩证结构，不同于线性进步观。
    归根万物最后都回到自己的根上。指万物纷纭变化之后各自返回其本始根源。老子以草木归根为喻，说明"复"是宇宙过程的归宿。"根"喻道或本始状态；"归"隐含自然、必然之义，非外力驱迫。与"复命"构成递进：归根是现象描述，复命是本体指认。王弼以"各返其所始"解，归结点在"静"，即动之息处；河上公则与"精神"相联，谓神不散则归根，通向养生内丹的"返本还元"；王夫之从气化论出发，反对有一个悬空的"本根"可归，认为"归根"只是气之聚散节律的描述，不可以为实有一物。
    复命回到根上，就叫回归本来的生命。指万物返回本根即是回复其本然的性命。"命"在此不作命运解，而指所受于道的本然之性。"命"在先秦有"天命"与"性命"两义，此处近后者；"复命"即复其性命之正，与《中庸》"天命之谓性"可对照，但老子不作道德形上学解，而作自然生化解。河上公与道教内丹传统将"复命"解为"返本还元"的修炼工夫，实指精气神归复；王弼则解为"静"之极处即是命之常然，偏向本体论；成玄英以重玄之道双遣有无，认为"复命"连"复"本身亦不可执，否则仍落一边。
    常万物运行中那个不变的老规矩。指恒常、不易的法则。老子认为万物虽变动不居，其复归之则恒常不变，故称"常"。"常"与"非常"（一章）相对，但非现象背后的抽象共相，而是"复命"所显的恒常性本身；在老子体系中"常"兼具规律义与本体义。王弼以"常"为"不偏不彰"之谓，强调其非可命名的对象；韩非《解老》以"理"释常，把老子的常道纳入法家的客观规律框架，是早期最重要的理性化解读；现代学者陈鼓应倾向于把"常"理解为自然规律，而葛兆光提醒这是现代概念投射，老子之"常"仍带强烈的宇宙论—宗教性底色。
    明懂了那个不变的规矩，就叫明白。指知晓恒常之道而生的智慧。老子以"知常曰明"界定"明"，与下文"不知常，妄作凶"构成正反对照。"明"在老子中与"明道若昧"（四十一章）并存，指内在的照察而非外显的精明；与"自知者明"（三十三章）相呼应，共同构成内向的智慧观。王弼以"明"为"常道之照"，与"无"体相通；河上公释为"内视"之明，与养生之"神明"相接；成玄英以重玄双遣解，"明"亦不可执，执明则成翳，此说与佛教"般若不可得"高度同构，是佛道交涉的典型痕迹。
    妄作不懂规矩就乱来，叫作妄作。指不知恒常之道而任意行动，老子判其结果为"凶"。"妄"训虚妄、无据；"作"为作为、造作。与老子"无为"主张直接对立，是"有为"之失的极端形态。王弼以"妄作"为违常之动，其凶在于失其本；河上公则从治身解，谓妄作伤神；王夫之从气化节律立论，认为妄作是逆气之动，凶非天罚而是势之必然，此解带有鲜明的反目的论色彩。
    容懂了规矩，心就宽了，能装得下人和事。指知常之后心胸开阔、无所不包。老子言"知常容"，把认知的深化与德性的扩展连成一线。"容"为包容、容受。在老子中与"虚"相通：虚故能容，容故能公。此处的"容"是境界语，非道德命令。王弼以"无所不包容"解，与"以无为本"一脉相承；苏辙以"无心而应"释容，明显吸收佛教"无住"之说；儒家学者如王安石则倾向以"容"通于"宽"，把老子此章纳入可接受的治道范围，可见儒道之间在德目层面的互相挪用。
    公心宽了，看事就公平，不偏心。指无所偏私的公正。老子以"容乃公"标出由包容而生的公正品格。"公"与"私"相对；老子之"公"不是制度性的正义，而是由无我而来的无私，其根据在"容"而不在法。王弼以"公正无私"解，归本于无；韩非则以"公"为法与国之公，与老子之"公"名同实异，是法家化读老的典型案例；陈鼓应指老子的"公"带有"天地不仁"式的非人格性，与儒家由亲疏推恩的"公"根本不同。
    王公平到极致，才配得上"王"这个字。老子谓"公乃王"，指公正无私者方能成就真正的"王"道。"王"在此非具体爵位，而是与道合德的境界称谓。"王"在先秦兼有政治与德性二义；老子四章"王亦大"可与本章互参，可见"王"在其体系中属于"四大"之一的位格，非单纯统治者。河上公直接以"为人所归往"释王，保留政治义；王弼则以"王"为"与天合德"之名，走向本体化的位格解；刘笑敢指出老子对"王"的处理实际是"以道限王"，是战国语境下对君主权力的规范性约束，具有鲜明的现实指向。
    天做到王的地步，才能跟天合上。指"王乃天"，即王者与天相合。"天"在此为自然之天、天道之天，非人格神。老子之"天"多指自然义（"天地不仁""天法道"），与周代天命观的天已有距离；"王乃天"表述的是一种存在层级上的上通。冯友兰认为老子把"天"彻底自然化，是中国哲学"天道观"转向的关键一步；葛兆光则指出民间与道教传统始终保留人格化、神格化的"天"，老子文本的自然化在精英层与民间层长期并存；成玄英以重玄解"天"，谓天亦假名，不落一际。
    道跟天合上了，才算跟"道"合上。老子谓"天乃道"，指出天亦以道为法（"天法道"，二十五章），道是最终的根据与法则。"道"在老子中兼具本原义与规律义；此处处于"容—公—王—天—道"的递进顶点，表明前面诸德目皆以道为其所以然。王弼以"无"释道，强调道"不可名""不可道"，偏向本体论的否定性描述；河上公则以"道"为"自然之谓"，偏取生成与养生；海德格尔晚年与人合译《老子》，以"道"（Weg/道路）为其"存在"之思的东方呼应，但明确说两者并不等同；陈鼓应强调老子之"道"应拆分为"实体义"与"规律义"两个层面理解。
    久合了道，才能真的长久。老子谓"道乃久"，指与道合一则能恒久。此"久"非时间上的无限延展，而是不因失道而中断的持续性。"久"在老子中亦见于"天长地久"（七章），其义为"不自生故能长生"，与"长久"的时间义不同，是一种由不争而得的存在持续性。王弼以"久"为"得常"之效，仍归于本体；河上公从养生解为"寿命长久"，形成道教长生说的经典依据，但此解与老子"死而不亡者寿"（三十三章）的内在张力历来为学者讨论；苏辙则以"未尝有间"释久，把时间义化解为境界义。
    没身不殆一辈子都不会栽跟头。指终身不遭遇危险。"没身"即终身，"殆"为危、殆。这是全章工夫次第的最后效验。"没身"在先秦文献中有"终身"义；"殆"与"危"义近。此句总结"知常—容—公—王—天—道—久"的链条，落到具体的人生安全上。河上公以养生解"不殆"，谓终身无患害；王弼则以"不殆"为不失其常，把安全义转为存在论的安然；韩非《解老》把"没身不殆"读为政治上的"无祸"，是法家化读老的代表；现代学者多认为此句体现了老子思想中"保身"与"体道"两条线索的汇合，而不同注家各执一端。
