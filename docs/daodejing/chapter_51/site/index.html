《道德经》

老子 著 · 老子五千言 · 第 51 章
“”

📜 原文

道生之，德畜之，物形之，势成之。是以万物莫不尊道而贵德。道之尊，德之贵，夫莫之命而常自然。故道生之，德畜之。长之育之，亭之毒之，养之覆之。生而不有，为而不恃，长而不宰。是谓玄德。

📖 四步导读

《第 51 章》四步导读


①书概览（5 分钟，建立全貌）

这一章回答一个朴素又根本的问题：万物从哪里来、又靠什么长大？老子给出四个环节——“道生之，德畜之，物形之，势成之”：道是源头，德是养育的力量，物给它形体，势让它最终成就。更妙的是，万物尊道贵德并非被谁命令，而是自然而然的。全章最重要的收获，是末尾那句“生而不有，为而不恃，长而不宰，是谓玄德”——真正的伟大，是给了生命却不占有、出了力却不居功、养大了却不控制。

②多问题意识关联

1. 如果你是父母，生养了孩子，你能做到“生而不有”——不把孩子当作自己的所有物吗？
2. 如果你是团队领导，做出了成绩，你能“为而不恃”——不把功劳记在自己名下吗？
3. 如果有人告诉你，万物生长背后没有发号施令的主宰，只是“常自然”，你会松一口气，还是感到不安？

③其他作者观点碰撞

- 荀子：主张“制天命而用之”，强调人主动裁制自然、化性起伪，与老子“长而不宰”、任其自然的姿态形成鲜明对照——一个要出手干预，一个要退让不控。
- 韩非：把“道”解释为客观法则，把“德”落在赏罚刑名上，《解老》《喻老》将老子玄虚的“玄德”转为君主治理术，恰是“生而不有”的反面——什么都想握在手里。
- 王阳明：讲“万物一体之仁”，生养万物出于本心自然流露，与老子“莫之命而常自然”有相通处，但阳明把它归给良知，老子则归于道。
- 维特根斯坦：认为许多“根源”问题是我们语言的误用所致，“道生之”这类表述更像是一种看世界的方式，而非可验证的因果说明。

④精读推荐（小白怎么读这章）

（1）第一遍（速览）：关注三个点——①“道、德、物、势”四个字分别承担什么角色，谁生、谁养、谁赋形、谁促成；②“莫之命而常自然”一句，注意老子如何解释万物尊道贵德的原因；③末尾“生而不有、为而不恃、长而不宰”三句排比，记下它们共同的姿态：给予而不控制。

>

（2）第二遍（细抠）：必看两个论证。其一，“道生之，德畜之，物形之，势成之”——看老子如何把万物生成拆成四个环节，道与德是根源与养育，物与势是条件与促成，缺一不可；其二，“夫莫之命而常自然”——这是全章的枢纽：尊道贵德不是被命令的，而是自然如此，正因无人强迫，这种尊崇才最真实、最稳固。

>

（3）第三遍（思辨）：一个值得追问的开放问题——“生而不有，为而不恃，长而不宰”作为“玄德”，在现实中真的可能吗？一个生养者若完全不“有”、不“恃”、不“宰”，养育关系还成立吗？还是说老子讲的是一种分寸，而不是彻底放手？

📝 结构化笔记

章节主旨：本章集中阐述道与德生养、畜育万物的根源性作用，说明万物尊道贵德出于自然，并以“生而不有、为而不恃、长而不宰”界定“玄德”。

📌 核心命题

  1. 道生发万物，德畜养万物，物赋予万物形体，势促成万物成就。
  2. 万物没有不尊崇道而珍贵德的。
  3. 道之尊与德之贵，并非出于谁的命令，而是常常自然而然。
  4. 道生养万物，德畜养万物，并长育、亭毒、养覆万物。
  5. 生养万物却不占有，作为却不恃功，长养却不主宰，这叫作玄德。

🔑 关键论据

  1. “道生之，德畜之，物形之，势成之。”
  2. “是以万物莫不尊道而贵德。”
  3. “夫莫之命而常自然。”
  4. “生而不有，为而不恃，长而不宰。是谓玄德。”

    道万物都是从它那里长出来的那个总根子。老子哲学的最高范畴，指宇宙万物的本原与根本规律。《老子》第二十五章谓"有物混成，先天地生……强字之曰道"；第五十一章则从生成论角度说道"生之"，即道是万物得以生的根源。与"德"相对而言，道是未分化的本根，德是道落实于万物之中的具体禀受。帛书甲乙本与王弼本第五十一章作"道生之，德畜之"，道为"生"之源，德为"畜"之力。王弼注："道者，物之所由也。"以"无"释道，强调"不塞其原""不禁其性"。陈鼓应《老子今注今译》指出此章"道"是"客观存在的终极根源"，非人格神。刘笑敢区分"老子之道"的本源义、规律义与境界义三系。王弼以"贵无"立说，认为道即"无"，万物"以无为体"而自生自化；河上公则把道解为"自然长生之道"，重在治身养生，谓人能体道则"精神不劳"。郭象注《庄》主"独化"，反对在万物之上另立一个生成者，认为"道"只是"物之所由"的空名，这与老子本章的生成论形成张力。海德格尔晚期讲"道说"（Sage）与大化（Ereignis），被部分学者比附为老子之道，但其"存在之真理"并不承担宇宙论的生成本源义，二者只是结构上的呼应而非内容上的等同。
    德万物从根子那里得到、并据以存活的那份本钱。指道赋予万物的具体禀性，以及畜养、护持万物的力量。《老子》第五十一章"德畜之"，与"道生之"对举：道是普遍的生成根源，德是使万物各成其性的内在依据。后世常"道""德"连称，但老子书中二者有体用、普遍与分殊之别。王弼注："德者，物之所得也。"即万物从道那里"得"到的东西即为德，此说本于《管子·心术上》"德者，得也"。成玄英以重玄义疏解，谓"道生德畜"皆为方便言诠，实则"道德"双遣。陈鼓应释"德"为"道寓于万物之中的部分"，是"道"的分殊化落实。河上公把"德"解为"德一"，谓"一"即道之子，人守德一则可"不劳"而养生，此章由此被读作内丹修养的纲领。王夫之以气化立论，认为"道"与"德"只是"太和絪缊"之气在通与分两个层面的称谓，道是"统之"、德是"分之"，反对把德看成从道那里外借来的东西。儒家自孔孟以降以"德"指道德品行（仁、义、忠、信），与老子此处本体论、宇宙论意义上的"德"判然有别，宋儒如朱熹虽读《老》，仍以"德"归之于性理，此即两家分野之所在。
    势万物之所以能长成、能成就的那股助推条件。指促成万物生长发育、成就自身的客观条件与趋势。《老子》第五十一章"势成之"，与"道生""德畜""物形"并列，构成万物生成的四个环节。势在此非权谋之势，而是自然条件、时位、环境所构成的促成力量。法家（如《韩非子·难势》）言"势"多指君主之位势，与此自然义之"势"不同。王弼本此句作"势成之"，帛书甲乙本亦有"势成之"之文；部分注家读"势"为"器"或"埶"，训为形势、条件。王弼注以"不塞其原"为说，谓万物"各得其成"，势即自然成就之所由。蒋锡昌《老子校诂》释"势"为"环境之力"。陈鼓应取"形势、条件"义，认为此环节表明老子生成论包含客观条件维度，非纯粹唯心。韩非在《难势》中把"势"界定为君主所居之位，主张"抱法处势则治"，是政治权位意义上的"势"，与老子此处自然条件义完全不同，但二者共享"凭借外在条件而成事"的语义结构。王夫之以气化释之，认为"势"即阴阳之气"相感相取"所成之态势，万物之成乃是气机之必然，非有主宰者使之然。怀特海的过程哲学以"合生"（concrescence）解释现实实有的生成，强调每一事件由既往事件"客观化"提供条件而成就，与"势成之"的条件性生成有可比较之处，但怀特海仍保留主体性摄受，老子则不言主体。
    玄德生了却不占有、做了却不自夸、养大了却不控制——这种德很深很远。指"生而不有，为而不恃，长而不宰"之德，是《老子》第五十一章对最高德性的概括。玄，幽深不测；德，畜养成就之功。玄德即不居功、不宰制、任万物自成的深德，与第十章"生而不有，为而不恃，长而不宰，是谓玄德"文句相合，可见此语为《老子》核心命题之一。王弼注："玄德深矣远矣，与物反矣，然后乃至大顺。"强调玄德之"反"，即返回于无、不居其功。苏辙《老子解》以"不有""不恃""不宰"为"无心"之德，谓"圣人无心而万物自遂"。成玄英重玄一系则谓"玄德"亦属方便名相，最终"德""玄"两忘。陈鼓应释为"最深远的德"，即不含有任何占有欲与支配欲的生成之德。河上公以养生解之，谓人能"生而不有"则"精神不去"，玄德即长生久视之德，把伦理命题转为身中修炼的口诀。郭象注《庄》主"独化""无心"，认为圣人只是"任万物之自为"，故不有、不恃、不宰并非道德克制，而是根本无"有之""恃之"之心，这与老子的"玄德"表述可相互发明。王夫之则认为"生而不有"正是气化之自然，天地无心而成化，非有意于"不有"。佛学中观以"缘起性空"说一切法无自性，禅宗讲"无心是道"，与"长而不宰"的无所执取有结构相似，但中观破的是自性见，老子立的是生成之德，出发点并不相同。

    L0万物从根子那里得到、并据以存活的那份本钱。
    L1指道赋予万物的具体禀性，以及畜养、护持万物的力量。《老子》第五十一章"德畜之"，与"道生之"对举：道是普遍的生成根源，德是使万物各成其性的内在依据。后世常"道""德"连称，但老子书中二者有体用、普遍与分殊之别。
    L2王弼注："德者，物之所得也。"即万物从道那里"得"到的东西即为德，此说本于《管子·心术上》"德者，得也"。成玄英以重玄义疏解，谓"道生德畜"皆为方便言诠，实则"道德"双遣。陈鼓应释"德"为"道寓于万物之中的部分"，是"道"的分殊化落实。
    L3河上公把"德"解为"德一"，谓"一"即道之子，人守德一则可"不劳"而养生，此章由此被读作内丹修养的纲领。王夫之以气化立论，认为"道"与"德"只是"太和絪缊"之气在通与分两个层面的称谓，道是"统之"、德是"分之"，反对把德看成从道那里外借来的东西。儒家自孔孟以降以"德"指道德品行（仁、义、忠、信），与老子此处本体论、宇宙论意义上的"德"判然有别，宋儒如朱熹虽读《老》，仍以"德"归之于性理，此即两家分野之所在。

    势

    L0万物之所以能长成、能成就的那股助推条件。
    L1指促成万物生长发育、成就自身的客观条件与趋势。《老子》第五十一章"势成之"，与"道生""德畜""物形"并列，构成万物生成的四个环节。势在此非权谋之势，而是自然条件、时位、环境所构成的促成力量。法家（如《韩非子·难势》）言"势"多指君主之位势，与此自然义之"势"不同。
    L2王弼本此句作"势成之"，帛书甲乙本亦有"势成之"之文；部分注家读"势"为"器"或"埶"，训为形势、条件。王弼注以"不塞其原"为说，谓万物"各得其成"，势即自然成就之所由。蒋锡昌《老子校诂》释"势"为"环境之力"。陈鼓应取"形势、条件"义，认为此环节表明老子生成论包含客观条件维度，非纯粹唯心。
    L3韩非在《难势》中把"势"界定为君主所居之位，主张"抱法处势则治"，是政治权位意义上的"势"，与老子此处自然条件义完全不同，但二者共享"凭借外在条件而成事"的语义结构。王夫之以气化释之，认为"势"即阴阳之气"相感相取"所成之态势，万物之成乃是气机之必然，非有主宰者使之然。怀特海的过程哲学以"合生"（concrescence）解释现实实有的生成，强调每一事件由既往事件"客观化"提供条件而成就，与"势成之"的条件性生成有可比较之处，但怀特海仍保留主体性摄受，老子则不言主体。

    玄德

    L0生了却不占有、做了却不自夸、养大了却不控制——这种德很深很远。
    L1指"生而不有，为而不恃，长而不宰"之德，是《老子》第五十一章对最高德性的概括。玄，幽深不测；德，畜养成就之功。玄德即不居功、不宰制、任万物自成的深德，与第十章"生而不有，为而不恃，长而不宰，是谓玄德"文句相合，可见此语为《老子》核心命题之一。
    L2王弼注："玄德深矣远矣，与物反矣，然后乃至大顺。"强调玄德之"反"，即返回于无、不居其功。苏辙《老子解》以"不有""不恃""不宰"为"无心"之德，谓"圣人无心而万物自遂"。成玄英重玄一系则谓"玄德"亦属方便名相，最终"德""玄"两忘。陈鼓应释为"最深远的德"，即不含有任何占有欲与支配欲的生成之德。
    L3河上公以养生解之，谓人能"生而不有"则"精神不去"，玄德即长生久视之德，把伦理命题转为身中修炼的口诀。郭象注《庄》主"独化""无心"，认为圣人只是"任万物之自为"，故不有、不恃、不宰并非道德克制，而是根本无"有之""恃之"之心，这与老子的"玄德"表述可相互发明。王夫之则认为"生而不有"正是气化之自然，天地无心而成化，非有意于"不有"。佛学中观以"缘起性空"说一切法无自性，禅宗讲"无心是道"，与"长而不宰"的无所执取有结构相似，但中观破的是自性见，老子立的是生成之德，出发点并不相同。

## [第 51 章]

道生之，德畜之，物形之，势成之。是以万物莫不尊道而贵德。道之尊，德之贵，夫莫之命而常自然。故道生之，德畜之。长之育之，亭之毒之，养之覆之。生而不有，为而不恃，长而不宰。是谓玄德。
