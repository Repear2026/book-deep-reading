📜 原文

📖 四步导读

《第 77 章》四步导读


①书概览（5 分钟，建立全貌）

这一章用“张弓”作比：弦位高了就压低，低了就抬高，拉得太满就减一点，不够就补一点。老子借此说“天之道”总是损有余而补不足，而人间的做法恰恰相反，是剥夺不足的去供养有余。于是引出唯一能“以有余奉天下”的人——有道者，并以圣人“为而不恃、功成而不处、不欲见贤”收尾。有趣之处在于：它把一条看似抽象的宇宙法则，直接变成对社会分配与个人姿态的伦理判决。最重要的收获是：在老子这里，“不居功、不显贤”是从天道推出来的结论，并非谦虚的美德。

②多问题意识关联

如果社会运转的真实规则总是“损不足以奉有余”，那么一个坚持“补不足”的人靠什么活下去？

>

如果“天之道”真会自动削平高者、抬举低者，那人的努力与制度设计还剩下什么位置？

>

如果你做了事却不自恃、成了功却不居功，别人凭什么知道你“贤”？这种“不欲见贤”是智慧还是自我抹除？

③其他作者观点碰撞

荀子：主张“制天命而用之”，认为天道有常、不因人事而变，人应当以礼义和制度去组织分配；他未必相信天会“自动补不足”，而会把“损有余补不足”看作需要人为设计的礼制工程。

>

韩非：从“人之道”的冷酷面出发，认为趋利避害是人性常态，贫富分化不靠道德感化解决，而靠赏罚与法度；他可能认为老子对“有道者”的期待过于依赖个人品格。

>

王阳明：会赞同“不欲见贤”，但会把根据从天道移到心上——不居功是因为本来就没有“我之功”可居，良知流行处自然不着痕迹，与老子“为而不恃”有微妙的呼应也有分歧。

>

涂尔干：从社会学看，“损有余补不足”类似集体良知对社会交换的调节功能；一个社会若长期“损不足以奉有余”，会破坏有机团结的道德基础，这与老子对“人之道”的批判可以对话。

>

罗素：会提醒说，“天之道”是一种自然主义谬误的诱惑——从“自然如此”推不出“应当如此”；但他也会承认，老子对分配不公的直觉批判具有持久的伦理力量。

④精读推荐（小白怎么读这章）

（1）第一遍（速览）：关注三个点——第一，“张弓”这个比喻到底在比什么（是高下、有余不足的调节动作）；第二，“天之道”与“人之道”的对照结构，注意老子用“则不然”三字把人间做法整个翻转过来；第三，结尾三句“为而不恃、功成而不处、不欲见贤”是如何从前面天道论述落到圣人品格上的。

>

（2）第二遍（细抠）：必看两个论证。其一，“天之道，其犹张弓与”到“损有余而补不足”——这是全章唯一的比喻性论证，要问：张弓的“抑、举、损、补”是同时发生的还是选择性的？老子的天道是描述还是规范？其二，“孰能有余以奉天下，唯有道者”——这是一个反诘加限定，要抠：为什么“有余”者未必能“奉天下”？“有道”在这里是能力条件还是道德条件？这两处撑起了全章的逻辑骨架。

>

（3）第三遍（思辨）：该追问的一个开放问题是——如果“天之道”真的会自动损有余补不足，那么“有道者”的“以有余奉天下”究竟是顺应天道的多余动作，还是在天道失灵处的人为补救？换句话说，老子是在描述一个已经运行的宇宙秩序，还是在召唤一种尚未实现的人间理想？这个追问会决定你把本章读成“宇宙论”还是“政治伦理宣言”。

📝 结构化笔记

章节主旨：本章通过“张弓”比喻对比天之道与人之道，揭示天道抑高举下、损余补足的调节原则，并据此提出“有道者”能以有余奉养天下，最后落实为圣人为而不恃、功成不处、不欲见贤的品格。

📌 核心命题

  1. 天之道犹如张弓，高者抑之、下者举之，有余者损之、不足者补之，即损有余而补不足。
  2. 人之道与天之道相反，是损不足以奉有余。
  3. 能拿有余来奉养天下的，只有有道者。
  4. 圣人做事而不自恃，功成而不居功，不愿显露自己的贤能。

🔑 关键论据

  1. 天之道，其犹张弓与？高者抑之，下者举之；有余者损之，不足者补之。
  2. 天之道，损有余而补不足。人之道则不然，损不足以奉有余。
  3. 孰能有余以奉天下，唯有道者。
  4. 是以圣人为而不恃，功成而不处，其不欲见贤。

💡 新概念

天之道
指自然界那种把高的压低、把低的抬举、把多余的减损、把不足的补足的运行方式。
人之道
指人间世俗的做法，与天道相反，是削减不足者的东西去奉养有余者。
张弓
拉开弓弦的动作，本章用它来比喻天道抑高举下、损余补不足的调节方式。
有道者
指能够以自己多余的部分奉养天下的人，即体认并遵循天道的人。
为而不恃，功成而不处
做了事却不依仗自己的作为，事情成了也不居功自处。
不欲见贤
不希望把自己的贤能显露出来。

❓ 我的错题本

    📚 术语表（L0-L3）

    L0 一句话 / L1 教材级 / L2 学术级 / L3 哲学反思

    术语L0 一句话（普通人能懂）L1 教材级别（中文百科）L2 学术级别（引用原学术语）L3 哲学/思想史反思（不同流派怎么理解）
    天之道大自然自有一套办法：多的减一点，少的补一点，高的压一压，低的抬一抬。老子用语，指自然界运行所遵循的法则，其特点是"损有余而补不足"，即自动趋向平衡与均平，犹如张弓时调整高低。与"人之道"相对而言。帛书甲乙本、王弼本均作"天之道，损有余而补不足"。"天"非人格神，而是自然总体的运行秩序（陈鼓应释为"自然规律"）；"道"在此指法则义而非本体义。王弼以"无"为本，认为天之道即自然无为、不假人为的"至均"之理，与名教人为的等差相对；河上公则从养生解，以"天道"为阴阳二气的自然调匀，人当效之以调身；荀子一派（儒家）则批评"天"无意志，主张"制天命而用"，把天还原为自然物象而非价值范本，与老子以天为则的立场形成对立。
    人之道人间的做法往往相反：穷人本就不够，还要被拿去供养本已富足的人。老子用语，指世俗社会的行为法则，特征是"损不足以奉有余"，即剥夺贫者以增益富者，与天之道的均平趋向相反。王弼本作"人之道则不然，损不足以奉有余"。"人之道"非泛指一切人为，而特指失道之后的社会实态（刘笑敢称为"实然"而非"应然"）；与"天之道"构成一对反价值判断。王弼认为人之道源于"有为"与"名分"的执着，是失无崇有的结果，故主张返无；郭象则主张"独化"，认为社会等差各安其分亦是自然，不必强以天道齐之，对老子此章的反差有一层消解；韩非从法家角度读老，把"损有余"解为君主赏罚的均衡之术，转向政治操作而非道德批判。
    张弓就像拉弓：弦拉高了要往下按，拉低了要往上抬。本章的比喻用语，指拉开弓弦时调整弓臂高低以求平衡的动作，老子借以喻天道抑高举下、损余补足的调节方式。王弼本"天之道，其犹张弓与？高者抑之，下者举之"。"张弓"一说为"张弓弦"，一说涉"弓"之张弛调节；苏辙解为"张弓者抑高举下，然后适均"，强调"适均"即恰到好处的中道。河上公以养生解"张弓"，谓调和气息如调弓弦，高者抑之使气不上浮，下者举之使气不下坠，属身中之术；苏辙以"适均"释之，近于儒家中庸的均衡观，但落在自然无为上；王夫之以气化论解，认为张弓之喻说的是阴阳二气自然消长的"调剂"，非人有意的均贫富。
    有道者真正懂道的人，自己有余就去帮天下的不足，而不是反过来搜刮。指体认并践行天道的人，其行为特征是以己之有余奉养天下之不足，功成而不居，不以贤能自显。王弼本"孰能有余以奉天下？唯有道者"。"有道者"与"圣人"在此章互文，指能"法天"而行者；陈鼓应释为"能行天道的人"，其判准在"损有余以补不足"的实践，而非认知上的知解。王弼以"无"为本，认为有道者之所以能奉天下，正因其"无身无我"，不以有余自累；庄子在《逍遥游》《齐物论》中把这类人推至"至人无己、神人无功、圣人无名"的境界，重心从"补不足"的外向施为转向内在的无待；郭象则强调"各安其分"，认为有道者不必刻意均平，只须使物各得其性，与老子"以有余奉天下"的主动施为颇有距离。
    为而不恃，功成而不处事情做了却不拿它当本钱，成功了也不赖在那个位子上。老子中反复出现的德目，指有所作为而不自恃其能，事成而不居功自处，与第二章"功成而弗居"、第五十一章"生而不有，为而不恃"义同。王弼本"是以圣人为而不恃，功成而不处"。"恃"为依仗义，"处"为居止义；此二句属老子"无为而无不为"的实践描述，非消极不为，而是"为"中不带占有与自矜（楼宇烈释"不恃"为"不有其功"）。王弼以"贵无"解，认为不恃不处正因"无"可恃可处，功成即归于无，与"崇本息末"相合；佛家中观一系（如僧肇《不真空论》）可与此互读，"为而不恃"近于"作而无作"、缘起性空而不碍行事；海德格尔论"泰然任之"（Gelassenheit）与不执于作为的态度有形式上的呼应，但其存在论背景与老子的生成论不同，不可直接等同。
    不欲见贤不希望把自己的贤能露出来给人看。指不以贤能自炫、不使己之贤明显露于人的态度，是"功成不处"在外在表现上的延伸，与老子"自见者不明"（第二十四章）一脉相承。王弼本"其不欲见贤邪"。"见"读为"现"，即显露义；"贤"在此指才能、德行的优越。此句以反问出之，表明有道者之"不欲现贤"恰因其已无"贤"可恃（苏辙解为"不欲见其贤以加人"）。王弼以"无"为本，认为"贤"亦是"有"之执，见贤即着于名，故圣人"不以贤临物"；庄子《德充符》以"德有所长而形有所忘"发挥此意，贤者不自知其为贤，与老子相承；儒家（如孟子、荀子）则正面肯定"贤"的价值与"尚贤"的必要，荀子更言"尚贤使能"，与老子"不欲见贤"构成直接对立，是儒道在政治伦理上的关键分歧；陈鼓应从社会批判角度指出，此语针对的是当时"尚贤"风气所生的争竞之弊。

    人之道

    L0人间的做法往往相反：穷人本就不够，还要被拿去供养本已富足的人。
    L1老子用语，指世俗社会的行为法则，特征是"损不足以奉有余"，即剥夺贫者以增益富者，与天之道的均平趋向相反。
    L2王弼本作"人之道则不然，损不足以奉有余"。"人之道"非泛指一切人为，而特指失道之后的社会实态（刘笑敢称为"实然"而非"应然"）；与"天之道"构成一对反价值判断。
    L3王弼认为人之道源于"有为"与"名分"的执着，是失无崇有的结果，故主张返无；郭象则主张"独化"，认为社会等差各安其分亦是自然，不必强以天道齐之，对老子此章的反差有一层消解；韩非从法家角度读老，把"损有余"解为君主赏罚的均衡之术，转向政治操作而非道德批判。

    张弓

    L0就像拉弓：弦拉高了要往下按，拉低了要往上抬。
    L1本章的比喻用语，指拉开弓弦时调整弓臂高低以求平衡的动作，老子借以喻天道抑高举下、损余补足的调节方式。
    L2王弼本"天之道，其犹张弓与？高者抑之，下者举之"。"张弓"一说为"张弓弦"，一说涉"弓"之张弛调节；苏辙解为"张弓者抑高举下，然后适均"，强调"适均"即恰到好处的中道。
    L3河上公以养生解"张弓"，谓调和气息如调弓弦，高者抑之使气不上浮，下者举之使气不下坠，属身中之术；苏辙以"适均"释之，近于儒家中庸的均衡观，但落在自然无为上；王夫之以气化论解，认为张弓之喻说的是阴阳二气自然消长的"调剂"，非人有意的均贫富。

    有道者

    L0真正懂道的人，自己有余就去帮天下的不足，而不是反过来搜刮。
    L1指体认并践行天道的人，其行为特征是以己之有余奉养天下之不足，功成而不居，不以贤能自显。
    L2王弼本"孰能有余以奉天下？唯有道者"。"有道者"与"圣人"在此章互文，指能"法天"而行者；陈鼓应释为"能行天道的人"，其判准在"损有余以补不足"的实践，而非认知上的知解。
    L3王弼以"无"为本，认为有道者之所以能奉天下，正因其"无身无我"，不以有余自累；庄子在《逍遥游》《齐物论》中把这类人推至"至人无己、神人无功、圣人无名"的境界，重心从"补不足"的外向施为转向内在的无待；郭象则强调"各安其分"，认为有道者不必刻意均平，只须使物各得其性，与老子"以有余奉天下"的主动施为颇有距离。

    为而不恃，功成而不处

    L0事情做了却不拿它当本钱，成功了也不赖在那个位子上。
    L1老子中反复出现的德目，指有所作为而不自恃其能，事成而不居功自处，与第二章"功成而弗居"、第五十一章"生而不有，为而不恃"义同。
    L2王弼本"是以圣人为而不恃，功成而不处"。"恃"为依仗义，"处"为居止义；此二句属老子"无为而无不为"的实践描述，非消极不为，而是"为"中不带占有与自矜（楼宇烈释"不恃"为"不有其功"）。
    L3王弼以"贵无"解，认为不恃不处正因"无"可恃可处，功成即归于无，与"崇本息末"相合；佛家中观一系（如僧肇《不真空论》）可与此互读，"为而不恃"近于"作而无作"、缘起性空而不碍行事；海德格尔论"泰然任之"（Gelassenheit）与不执于作为的态度有形式上的呼应，但其存在论背景与老子的生成论不同，不可直接等同。

    不欲见贤

    L0不希望把自己的贤能露出来给人看。
    L1指不以贤能自炫、不使己之贤明显露于人的态度，是"功成不处"在外在表现上的延伸，与老子"自见者不明"（第二十四章）一脉相承。
    L2王弼本"其不欲见贤邪"。"见"读为"现"，即显露义；"贤"在此指才能、德行的优越。此句以反问出之，表明有道者之"不欲现贤"恰因其已无"贤"可恃（苏辙解为"不欲见其贤以加人"）。
    L3王弼以"无"为本，认为"贤"亦是"有"之执，见贤即着于名，故圣人"不以贤临物"；庄子《德充符》以"德有所长而形有所忘"发挥此意，贤者不自知其为贤，与老子相承；儒家（如孟子、荀子）则正面肯定"贤"的价值与"尚贤"的必要，荀子更言"尚贤使能"，与老子"不欲见贤"构成直接对立，是儒道在政治伦理上的关键分歧；陈鼓应从社会批判角度指出，此语针对的是当时"尚贤"风气所生的争竞之弊。

## [第 77 章]

天之道，其犹张弓与？高者抑之，下者举之；有余者损之，不足者补之。天之道，损有余而补不足。人之道则不然，损不足以奉有余。孰能有余以奉天下，唯有道者。是以圣人为而不恃，功成而不处，其不欲见贤。
