📜 原文

📖 四步导读

《第 11 章》四步导读


①书概览（5 分钟，建立全貌）

这一章用三件家常东西讲一个反直觉的道理：车轮、陶罐、房子。我们习惯盯着“有”，也就是辐条、泥壁、门窗；老子却让我们去看“空”：正因中间空着，车才能转、罐才能装、屋才能住。所以他说“有之以为利，无之以为用”：实在的部分提供条件，空出来的部分成就功用。这是把抽象的“无”落实到手上可摸的经验里，也是全书有无之辩最亲切的一节。

②多问题意识关联

1. 如果你只欣赏杯子的花纹，却嫌它里面是空的，那这杯子还能用来喝水吗？
2. 如果一个团队把每个人的时间都排满、一点空隙不留，它还能应对突发变化吗？
3. 如果你把自己的人生填得满满当当，没有“留白”，那些空白真的是浪费吗？

③其他作者观点碰撞

- 荀子：主张“制天命而用之”，强调人主动加工外物、以“有”成事，与老子偏重“空处生用”形成一种张力：一个看重人为建构，一个提醒建构所依赖的空隙。
- 韩非：在《解老》《喻老》中最早系统注解老子，把“无之用”读作君主虚位、不以己意塞满臣下空间的治国术，将形上之“无”转为政治技术。
- 王阳明：讲“心无所住”“虚灵不昧”，认为心的空明才使应事接物灵通，与“当其无，有…之用”可相互印证，但落点在心上而非器物上。
- 维特根斯坦：后期强调意义在于使用，一个词的生命在语言实践的“空隙”与语境中；可与“无之以为用”对看：功能不在实体，而在被留出的空间。
- 海德格尔：在《物》等文中论壶，认为壶的“倾注”之所以可能，正因器皿中空，他把“空”看作聚集天、地、人、神的场所，与老子论陶器极为接近。

④精读推荐（小白怎么读这章）

（1）第一遍（速览）：抓三个关注点——三个类比是不是同一结构（辐条与毂、泥与器、门窗与室）；“当其无”中的“无”具体指什么（物理空间还是功能空隙）；末句“利”“用”二字的分工。

>

（2）第二遍（细抠）：必看两处论证。一是“三十辐共一毂，当其无，有车之用”：注意三十辐是“有”，毂中空是“无”，两者缺一不可，老子并非否定“有”。二是“凿户牖以为室，当其无，有室之用”：门窗是“有”开出的通道，恰恰是“有”造成了“无”，可见有无并非对立，而是相互成就。

>

（3）第三遍（思辨）：请追问——这个类比能推到多远？器物之“空”是被造出来的、有边界的空；那么人生、制度、语言中的“无”是否也需被“有”精心塑形才有用？如果“无”离开“有”的框定就无所依附，那老子说的究竟是“贵无”，还是“有无相生”？

📝 结构化笔记

章节主旨：本章以车轮、陶器、房屋三个日常器物为类比，集中阐明“有”提供便利条件、“无”成就实际功用的辩证关系；在全书道论中，它把抽象的“无”落到具体生活经验中，为后文继续展开有无、虚实、无为等主题奠定基础。

📌 核心命题

  1. 三十根辐条汇聚到同一个毂，正因为毂中间是空的，车才有承载的作用。
  2. 把泥土做成陶器，正因为器物中间是空的，器物才有盛物的作用。
  3. 开凿门窗建成屋子，正因为屋子内部是空的，屋子才有居住的作用。
  4. 所以“有”提供了便利条件，“无”成就了实际的功用。

🔑 关键论据

  1. 三十辐共一毂，当其无，有车之用。
  2. 埏埴以为器，当其无，有器之用。
  3. 凿户牖以为室，当其无，有室之用。
  4. 故有之以为利，无之以为用。

    毂车轮正中间那个空心的圆木，三十根辐条都插在它上面，车轴也从它中间穿过。毂是车轮中心的圆木部件，周围凿有榫眼以容纳辐条，中心有圆孔以贯车轴。《老子》第十一章以"三十辐共一毂，当其无，有车之用"说明器物的功用依赖其中空之处。原文作"三十辐同一毂，当其无，有车之用也"（帛书本"共"作"同"）。"当"读为"尝"/"当"，训"因、由"；"无"在此指毂中穿孔的虚空处，即实体结构中被让出的位置，非全无。河上公注："古者车三十辐，法月数也。共一毂者，毂中有孔，故众辐共凑之。治身者当除情去欲，使五藏空虚，神乃归之。"王弼《老子注》以"无"为体："毂所以能统三十辐者，无也。以其无能受物之故，故能以实统众也"，把毂中之空提升为"以无为本"的本体论喻象，认为"有之所始，以无为本"。河上公则把毂解为治身之喻，主张"除情去欲、五藏空虚"，走养生与身国同构一路，与王弼的玄学本体论取向迥异。郭象在注《庄子》时反对"以无为本"，主张"独化于玄冥""无既无矣，则不能生有"，若以此立场读毂，则空处之"用"只是器物结构性的"自尔"，不承认有一个更高的"无"作本根。现代研究者陈鼓应强调此章的"无"是"空处、留白"的具体义，反对把它直接读成西方意义上的本体论虚无。
    埏埴把泥巴加水和匀、捏成陶器坯子的那套手艺。埏，揉和；埴，黏土。"埏埴"即和水揉泥、制坯为器。《老子》第十一章："埏埴以为器，当其无，有器之用。"原文"埏埴为器，当其无，有埴器之用"（通行本作"有器之用"）。"埏"字从"延"得声，训"和也、揉也"（《说文》系"抟"义近）。关键在"当其无"：器物之"用"系于坯体围出的中空容积，而非泥料本身。苏辙《老子解》："陶者以埏埴为器，其中虚，故可以盛。"河上公注走治身一路："埏，和也；埴，土也。和土以为饮食之器。器中空虚，故得有所盛受。治身者当除情去欲，使五藏空虚，神乃归之。"把制陶读成"虚心实腹"的养生工夫。王弼则从"有—无"的体用结构切入，谓"言无者，有之所以为利，皆赖无以为用也"，埏埴所造之器所以"利"，正在其"无"能受。成玄英在《道德经义疏》中又以重玄双遣解之，谓"非唯器之无用，亦乃有亦不有"，防止执着于"空"一边。王夫之《老子衍》则以气化论为底，认为虚实皆一气之聚散，反对把"无"当成悬空的实体性本原。
    户牖房子的门和窗，凿开墙上两块空的窟窿，人才能进出和采光。户为单扇门，牖为窗。《老子》第十一章："凿户牖以为室，当其无，有室之用。"指凿墙为门窗，室内才成其为可居之室。"户"为单扉之门，"牖"为穿壁之窗（《说文》："牖，穿壁以木为交窗也"）。此句与毂、埏埴并举，构成"车—器—室"三重类比，句法上同一"当其无，有X之用"的公式反复三次，属《老子》典型的"三事互证"修辞。楼宇烈指出，这种"三叠"句法是《老子》"以事明理"的常式。王弼据此立论："木、埴、壁所以成三者，而皆以无为用也。言无者，有之所以为利，皆赖无以为用也。"把门窗之空抽象为一般性的"无—用"结构。河上公则解为治身之门户："凿户牖以为室，言人之为室，当空虚其中，乃可居止。治身者当虚心，则神明来舍。"道教内丹家更直接以"户牖"喻人之九窍、玄关，讲"开窍通神"。庄子在"室无空虚，则妇姑勃豀"（《外物》）中也用空间比喻心之虚，可与老子互参，但庄子重心在"心斋""虚室生白"，落点是境界而非器用。海德格尔论"物"时强调"位置"（Ort）与"空间"由物之"让空"（Einräumen）而成，与中国古代以器之空虚言用，问题意识有可对照处，但海氏之"无"通向"存在之澄明"，与老子生成论脉络的"有生于无"并不等同。
    有之以为利有了实打实的材料和形体，才提供了"能用得上"的条件。《老子》第十一章末句："故有之以为利，无之以为用。""有"指器物实体，为功用提供凭借；"利"训"便利、凭借、条件"。与"无之以为用"构成对文。通行本作"有之以为利，无之以为用"，帛书甲本作"有之以为利，无之以为用也"，文字大体一致。此处"利"非功利之利，而是"赖以成事之凭借"，与"用"分属两个层次："有"提供条件性、"无"提供功能性。王弼注："有之所以为利，皆赖无以为用也。"是以"无"统"有"，二者非平列。王弼把"有—无"定为"利—用"的层级关系，实为"以无为本、以有为末"的体用论张本，末必依本。河上公则读成身国修养论，"有"为形身，"无"为神气，二者相须，偏重"养神"以全生，不走本体论。郭象若在此处，会反对把"无"抬为本，"有之以为利"便是各当其分、自尔自得，无所待于无。苏辙《老子解》以"有"为器、"无"为道，谓"有之为利，人莫不知；无之为用，则天下莫之知"，视为常人对"空"的盲视。王夫之以气化立论，谓有与无"皆气之聚散"，反对将"无"悬空为体。现代学者刘笑敢指出，"有—无"在《老子》中兼有"存有论"与"价值论"两重义，不宜单向还原为任何一种。
    无之以为用真正让东西"好使"的，是空出来的那部分。《老子》第十一章核心命题。"无"指器物中被让出的虚空处（毂孔、器中、室中、户牖），"用"即实际功用。全章以车、器、室三喻证成"空处生用"。与"有之以为利"对文互训。"当"（因、由）+ "其无"反复三次，构成老子特有的"功能性虚空"论证：实者所以为"利"，虚者所以为"用"。王弼注："言无者，有之所以为利，皆赖无以为用也。"此处"无"在其体系中已从器物之空升为"本"，即以无为本。"用"在先秦常训"功用、施用"，与"体"相对，魏晋以后才成"体用"范畴。王弼以"贵无"立说，将"无"本体化，主张"天地虽广，以无为心"，此章遂成其"以无为本"的经典依据。河上公从养生立说，谓"除情去欲，五藏空虚，神乃归之"，把"无"解为虚静工夫，非本体。郭象反对"无"能生有、能成有，主张万物"独化""自尔"，若依其说，则"空处之用"只是结构之自然，不须立一个"无"为本。佛学中观学以"缘起性空"读之，认为"无"即自性空，非另一实体，"用"依缘而起；禅宗则更彻底，讲"无心""无念"，把"空"落在当下心地。海德格尔论"无"为"存在者的遮蔽"与"无化"（das Nichten），与老子"无之以为用"形式相近而方向相反：海氏之无指向存在之开显，老子之无服务于生成与功用。现代学者陈鼓应、楼宇烈均提醒，此章的"无"首先须读作"空处、留白"，其本体论义是后起的诠释，不可倒推为《老子》原义。

    毂
