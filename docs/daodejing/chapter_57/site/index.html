《道德经》

老子 著 · 老子五千言 · 第 57 章

📜 原文

以正治国，以奇用兵，以无事取天下。吾何以知其然哉？以此。天下多忌讳，而民弥贫；民多利器，国家滋昏；人多伎巧，奇物滋起；法令滋彰，盗贼多有。故圣人云：我无为而民自化，我好静而民自正，我无事而民自富，我无欲而民自朴。

📖 四步导读

《第 57 章》四步导读


①书概览（5 分钟，建立全貌）

这一章是老子政治哲学的一段纲领：治国靠正道，用兵靠奇变，而“取天下”的关键却是——不折腾。老子用一条条反证链（忌讳多→民贫困，利器多→国昏乱，伎巧多→奇物起，法令多→盗贼多）来说明：政令越繁杂，秩序反而越混乱。最有意思的是，它把“治国好不好”的标准从“管得严不严”翻转成“扰不扰民”。最大的收获是结尾四句：无为而民自化，好静而民自正，无事而民自富，无欲而民自朴。

②多问题意识关联

如果你所在的小区物业把规章从十条加到一百条，你的生活会更有序还是更憋闷？

>

如果一家公司严禁一切“越界”做法，员工还会不会做出新产品、新办法？

>

如果政府把所有想得到的不良行为都写进法律，剩下的“法外空间”会由谁来填？

③其他作者观点碰撞

韩非（《韩非子·有度》）：与老子正好相反，“奉法者强则国强”——法要明、要公布、要严格执行，秩序不来自少法，而来自法必行、赏罚必信。

>

荀子（《荀子·富国》等）：人“群而无分则争”，所以必须靠礼义法度来划定界限。他不认为去掉规范就能自然有序，反而认为规范是人群得以共存的前提。

>

王阳明：走的是老子的同侧——理不在外面的条文章程里，而在“良知”之中；把条目越订越细，未必能让人变好，反容易“务外而遗内”。

>

维特根斯坦（《哲学研究》§201 关于“遵守规则”的讨论）：任何规则都无法自行决定下一步怎么应用，规则总是靠共同的生活实践来支撑。这从语言哲学一侧，提示了“法令滋彰”为何不能自动产生秩序。

>

福柯（《规训与惩罚》）：监狱与规训机制并不消除违法，反而在生产一种可被管理的“过失犯罪”人群。这与老子“法令滋彰，盗贼多有”构成一种现代的呼应，但福柯的结论是权力无所不在，而非“无欲而民自朴”。

④精读推荐（小白怎么读这章）

（1）第一遍（速览）：抓住三个关注点——开头三句纲领（正、奇、无事，分别对应治国、用兵、取天下三件事，不要混用）；中间四个“多则……”形成的反证链；结尾圣人四“自”的对照（无为、好静、无事、无欲，对应自化、自正、自富、自朴）。

>

（2）第二遍（细抠）：重点抠两处论证。第一处是“法令滋彰，盗贼多有”：老子凭什么说外在强制越多、越不生秩序？这里的因果是“民被逼得无路可走”，还是“禁令本身激出规避行为”？第二处是结尾四句的对应关系：为什么“无为”对“自化”、“无欲”对“自朴”？这四组是不是层层递进，还是并列列举？想清楚这两点，全章的逻辑骨架就立起来了。

>

（3）第三遍（思辨）：留给自己的开放问题是——如果“少发政令、少造事”就是好政治，那么面对食品安全、环境污染、公共卫生这类“不管就出事”的领域，“无事”的边界应该划在哪里？老子没有正面回答，而这正是这一章最值得追问的地方。

📝 结构化笔记

章节主旨：本章集中阐述老子的治国用兵原则与无为政治逻辑：以正道治国、以奇变用兵、以不扰事取天下，并通过“忌讳—贫困”“利器—昏乱”“伎巧—奇物”“法令—盗贼”的因果链，反证为政者少干涉、少造事、少贪欲的必要性。

📌 核心命题

  1. 以正治国，以奇用兵，以无事取天下。
  2. 天下忌讳多则民更贫困。
  3. 民多利器则国家滋昏。
  4. 人多伎巧则奇物滋起。
  5. 法令滋彰则盗贼多有。
  6. 圣人无为而民自化，好静而民自正，无事而民自富，无欲而民自朴。

🔑 关键论据

  1. 治国当以正道为本，用兵当以奇变为法，取天下当以不扰民、不造事为原则。
  2. 为政者禁令忌讳越多，民众越受束缚而趋于贫困。
  3. 民众掌握过多锐利器物或武器，国家反而容易陷入昏乱。
  4. 民间技艺巧作越繁盛，奇异之物越容易滋生。
  5. 法令越彰显繁多，盗贼反而越多，说明外在强制未必带来秩序。
  6. 为政者若能做到无为、好静、无事、无欲，民众将自化、自正、自富、自朴。

    📚 术语表（L0-L3）

    L0 一句话 / L1 教材级 / L2 学术级 / L3 哲学反思

    术语L0 一句话（普通人能懂）L1 教材级别（中文百科）L2 学术级别（引用原学术语）L3 哲学/思想史反思（不同流派怎么理解）
    以正治国用正当、清明、合乎常规的办法治理国家。语出《老子》第五十七章。“正”指清静无为之正道、常法，与“奇”相对。老子认为治国当以正，不以权术。王弼本作“以正治国”，王弼注：“以道治国，崇本以息末；以正治国，立辟以攻末。”河上公注：“正，正道也。治国当以正道。”陈鼓应译“以清静之道治国”。“正”与“奇”构成经与权、常与变的对举。王弼认为“以正治国”仍属“立辟以攻末”，不如“以道治国”崇本；河上公则以“正道”为治国之本，偏重治身与治国一体；苏辙《老子解》以“正”为“常”，认为“正”能胜“奇”；韩非《解老》以“理”释道、主张法度公开明确，可视为对“正”的法家式转写。
    以奇用兵用出其不意、灵活多变的方法用兵。“奇”与“正”相对，指权变、诈术、出人意料的战术。老子认为用兵不同于治国，可用奇。河上公注：“奇，诈也。用兵当以诈。”王弼注：“以正治国，立辟以攻末……故必至于奇用兵也。”苏辙以“奇”为“非正也”。陈鼓应译“以奇术用兵”。“奇正”范畴后为兵家《孙子》所发挥。河上公以“诈”解“奇”，近于兵家权谋；王弼则认为“奇”是“正”之穷，是“立辟攻末”的必然后果，带有批评意味；苏辙以“奇正相生”解，与《孙子》“奇正”之说相通；刘笑敢指出老子对“兵”持保留态度，“以奇用兵”是不得已而为之。
    以无事取天下不扰民、不生事，才能取得天下。“无事”即不制造烦苛政事、不扰攘百姓。“取天下”不是武力夺取，而是天下归附。河上公注：“无事，无徭役征召之事也。”王弼注：“无事，则民自富。”蒋锡昌：“无事即无扰也。”陈鼓应译“以不扰攘人民来治理天下”。王弼以“无”为本，认为“无事”是“崇本息末”的政治表现；河上公把“无事”与治身结合，主张“不烦不扰，精神内守”；黄老学派《管子·心术》讲“君无为而臣有为”，把“无事”理解为君主不亲细务；刘笑敢认为“无事”是“不强行干预”，与“自然”互为表里。
    忌讳统治者设下的种种禁令和禁忌。本章“天下多忌讳，而民弥贫”，“忌讳”指统治者制定的禁令、防禁，越多则百姓越贫困。河上公注：“忌讳，防禁也。”王弼注：“多忌讳，则民弥贫。”陈鼓应译“禁忌戒律”。帛书甲乙本并作“忌讳”，与通行本同。河上公从治身角度解“忌讳”为“防禁”，认为防禁过多伤民；王弼从“崇本息末”出发，认为忌讳多则民失其自然；韩非主张法应公开简明，反对隐秘难测的禁令，可与老子此句相参；陈鼓应指出这是老子对当时“政令烦苛”的批评。
    利器统治者手中的权谋、权柄和锐利工具。本章“民多利器，国家滋昏”，“利器”指权谋、权柄、兵甲等。河上公注：“利器者，权谋也。”王弼注：“利器，利国之器也。”苏辙：“利器，权谋也。”陈鼓应译“利器”为“权谋”，亦有解为“锐利武器”者。河上公以“权谋”解，认为民多权谋则国昏；王弼以“利国之器”解，认为“利器”是君主所执权柄，若下移则国昏；苏辙与三十六章“利器不可以示人”互文，认为权谋不可示民；楼宇烈指出“利器”兼含“权谋”与“兵器”二义。
    伎巧各种机巧、巧诈和过度的手工技艺。本章“人多伎巧，奇物滋起”，“伎巧”指机巧、巧诈，也指过度工艺。河上公注：“伎巧，巧诈也。”王弼注：“民多智慧，则巧伪生。”帛书作“人多知（智）”，知通智。陈鼓应译“伎巧”为“巧诈”。河上公从治身出发，认为“伎巧”伤朴；王弼以“智慧”释“伎巧”，认为巧伪生于智慧，与其“崇本息末”一致；庄子《天地》讲“有机事者必有机心”，《胠箧》主张“掊斗折衡而民不争”，可与老子“伎巧”相参；陈鼓应认为老子反对的是“巧诈”而非一切工艺。
    奇物稀奇古怪、奢侈邪僻的东西。本章“奇物滋起”，“奇物”指邪僻奇怪之物、奢侈之物。河上公注：“奇物，邪事也。”王弼注：“奇物，奇怪之物也。”陈鼓应译“邪奇之物”。有版本作“邪事”。河上公以“邪事”解，偏重道德教化；王弼以“奇怪之物”解，认为奇物生于“伎巧”；苏辙从“常”与“奇”对举，认为“奇物”是“不正”之物；现代学者指出“奇物”或指奢侈品、珍玩，与十二章“为腹不为目”相通。
    法令滋彰法令条文越来越多、越来越严。本章“法令滋彰，盗贼多有”，“滋”是更加，“彰”是显明。老子认为法令越繁，盗贼越多。王弼本作“法物滋彰”，河上公本作“法令滋彰”。王弼注：“法物，谓法令也。”河上公注：“法物，好物也。”陈鼓应据河上公本作“法令滋彰”，译“法令条文越彰显，盗贼反而越多”。河上公把“法物”解为“好物”，偏重治身；王弼解为“法令”，认为“法物”是“末”，“滋彰”则“本”失；韩非主张法应公开、必行，与老子此句形成张力——韩非《解老》强调法的客观性，老子则警惕法令膨胀；陈鼓应认为这是对“法治”过度化的批评，不是反对一切法。
    无为不妄为、不强加干预，顺其自然。老子核心概念。“无为”不是什么都不做，而是不妄为、不违反自然规律地干预。王弼注：“自然已足，为则败也。”河上公注：“无为，不施为也。”陈鼓应译“不妄为”。刘笑敢指出“无为”是“行为主体对自然状态的辅助”。王弼以“无”为本，认为“无为”是“崇本息末”；河上公以“治身”解“无为”，主张“精神内守”；黄老学派讲“君无为而臣有为”，《管子·心术上》以“心”喻君；庄子把“无为”推向“逍遥”“齐物”的精神自由；王夫之《老子衍》则批评“无为”若任其自然，将废人之有为。
    好静统治者喜好清静、不躁动。本章“我好静而民自正”，“静”与“躁”相对，指清静、不扰民。王弼注：“静，无欲也。”河上公注：“静，谓无欲也。”苏辙：“静者，不扰之谓也。”陈鼓应译“清静”。王弼以“静”为“无欲”的表现，与其“贵无”一致；河上公以“静”为治身之要，主张“安静”以养神；庄子讲“心斋”“坐忘”，把“静”推向精神修养；陈鼓应认为“好静”是“不扰民”的政治态度。

    L3王弼认为“以正治国”仍属“立辟以攻末”，不如“以道治国”崇本；河上公则以“正道”为治国之本，偏重治身与治国一体；苏辙《老子解》以“正”为“常”，认为“正”能胜“奇”；韩非《解老》以“理”释道、主张法度公开明确，可视为对“正”的法家式转写。
