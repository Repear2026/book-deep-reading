📜 原文

📖 四步导读

《第 71 章》四步导读


①书概览（5 分钟，建立全貌）

这一章只有三句话，却在讨论一个极难回答的问题：你怎么知道自己“不知道”？老子区分了两种认知状态——“知不知”（知道自己有所不知）是上等，“不知知”（不知道却自以为知道）是毛病。有趣的是，他开的药方是“病病”：把这个毛病本身当作毛病来盯着，才可能不犯。最重要的收获是：智慧不在于知道更多，而在于对“自己可能错”保持持续警觉。

②多问题意识关联

- 如果你坚信自己已经完全搞懂了一件事，结果却在关键时刻翻车——你回头会发现，问题出在“不懂”上，还是出在“不知道自己不懂”上？
- 如果一个团队里没人敢说“这个我不确定”，决策会变成什么样？“不知知”在组织层面会如何放大？
- 如果你每天睡前问自己一句“今天哪件事我可能想错了”，这个习惯会改变你的判断质量吗？还是只会让你更犹豫？

③其他作者观点碰撞

- 苏格拉底（柏拉图《申辩篇》）：宣称“我唯一知道的就是我一无所知”，与老子“知不知，上”遥相呼应；但苏格拉底把无知感转化为不断追问的对话，老子则把它收敛为一种内省的静观。
- 维特根斯坦（《逻辑哲学论》第 7 命题）：主张对不可言说者保持沉默，划定了语言表达的极限——与老子对认知边界的警觉相似，但维特根斯坦用的是逻辑分析，老子用的是修养工夫。
- 王阳明（《传习录》）：讲“知行合一”，认为真知必能行。若只是口头承认“我有所不知”，行为上仍自以为是、拒斥异见，按阳明看就仍是“不知知”的毛病，缺了“病病”的实践转化。
- 罗素（《哲学问题》）：指出许多日常“知识”只是程度不等的或然性信念，自认为确定的东西往往经不起推敲——这与“不知知，病”的诊断相通，但罗素相信科学方法能逐步修正，老子则更强调主体自身的警醒。

④精读推荐（小白怎么读这章）

（1）第一遍（速览）： 关注三个点——第一，“知不知”和“不知知”只差一个字的顺序，意思却完全相反，注意这个文字游戏背后的认知差异；第二，“病”字在本章出现了四次（“病”“病病”“不病”“病病”“不病”），看老子如何用同一个字在“毛病”和“把毛病当毛病”两个意思之间切换；第三，最末句“圣人不病，以其病病，是以不病”是全章的收束，注意它的因果链条。

>

（2）第二遍（细抠）： 必须看两处论证。第一处是“夫唯病病，是以不病”——这里的逻辑是：只有把“不知知”当成一种需要警惕的病，你才会去检查自己是否犯了它，从而真的不犯。注意老子没有说“知道了就不犯”，他说的是“病病”这个动作本身构成了“不病”的条件。第二处是“圣人不病，以其病病”——圣人不是天生没毛病，而是因为持续“病病”才没毛病，这把“圣人”从天赋异禀拉回到了修养功夫的层面。

>

（3）第三遍（思辨）： 追问一个问题——“病病”会不会陷入无穷倒退？如果你时刻警惕自己“自以为知”，那你怎么判断自己此刻的“警惕”本身是不是另一种“自以为知”？老子说的“病病”有没有一个停止点，还是它要求一种永不停歇的自我审视？这个循环有没有出口？

📝 结构化笔记

章节主旨：本章属于老子关于认知自觉与自我修养的短章，围绕“知”与“不知”的边界展开，指出真正的智慧在于知道自己有所不知，而认知上的根本毛病是不知道却自以为知道；圣人之所以无此毛病，正在于能把这个毛病当作毛病来警惕和对待。

📌 核心命题

  1. 知道自己有所不知，是最好的；不知道却自以为知道，是毛病。
  2. 只有把这种毛病当作毛病来对待，才能不犯这种毛病。
  3. 圣人没有这种毛病，正因为他把这种毛病当作毛病来对待，所以不犯这种毛病。

🔑 关键论据

  1. 知不知，上；不知知，病。
  2. 夫唯病病，是以不病。
  3. 圣人不病，以其病病，是以不病。

病病
把“不知却自以为知”这个毛病当成毛病来对待，保持警觉并加以修正。

    📚 术语表（L0-L3）

    L0 一句话 / L1 教材级 / L2 学术级 / L3 哲学反思

    知不知明白自己有不懂的地方，不装懂。语出《老子》第七十一章："知不知，尚矣。"指人对自己认知的边界有清醒自觉，知道自己所知有限，这是一种值得肯定的态度。老子把这种"自知其不知"视为上等的认知状态，与"不知知"相对。河上公注："知道言不知，是乃德之上。"以"德"论之，将认知的谦退纳入养生修德框架。王弼注此章重在"以不知为知"的玄理结构，强调圣人不以察察为明。陈鼓应释为"知道自己有所不知道，最好"，并联系第四十八章"为学日益，为道日损"，指认知的自我限定是体道的入口。王弼以"贵无"为本，认为真正的"知"是对"无"的体认，故圣人"无知"而无所不知，知不知是通向玄览的否定性环节；河上公从养生角度读为"不自满、保精气"，把认知谦退转为治身之术；郭象注《庄》主张"独化"，反对以更高的"道"统摄万物，故"知不知"不是向某个大全回归，而是各安其分、承认性分之限；苏辙以佛理解老，谓"不知而知，知而不知"，近于般若的"无分别智"；维特根斯坦在《逻辑哲学论》末尾提出"对于不可言说的东西必须保持沉默"，与"知不知"划定语言界限的旨趣可相参证，但一为逻辑分析、一为体道修养，指向不同。
    不知知不懂却以为自己懂，这是毛病。语出《老子》第七十一章："不知知，病也。"指本无真知却自以为知，是一种认知上的疾患。老子以此批评世俗中人常以己见为确定，蔽于成见而不自知。此"病"非身体之病，而是认知与心性上的偏蔽。王弼注："不知知之，病也。"以"知"之自限为病根。成玄英重玄学解此章，谓"不知而知，斯为病矣"，以双遣有无、遣之又遣的思路，把"自以为是"视为执著之病。刘笑敢指出老子此处体现"正言若反"的表达方式，以否定性语汇确立正面价值。郭象以"独化"立论，认为万物各当其分、无待于外，故批评"不知知"是越出性分而强作解人；庄子在《齐物论》中言"大知闲闲，小知间间"，并主张"是不是，然不然"，认为是非之辩本身即病，与老子此章互为呼应而又更彻底地消解是非；韩非《解老》以"道理"释老，把"不知知"读为不循事理而妄断，转向政治与法度的实用维度；佛学中观以"缘起性空"破一切自性见，"不知知"可类比为"增益执"——于无自性处执有自性；维特根斯坦晚期以"语言游戏"说明意义源于用法，越出用法而断言即产生"哲学病"，与老子"病"的隐喻结构上有可比性，但维氏以治疗语言误用为务，老子以体道修身为归。
    病病把这"不懂装懂"的毛病当成病来治、来防。语出《老子》第七十一章："夫唯病病，是以不病。"前一"病"为动词，意为把……视为病、以之为患；后一"病"指"不知知"之病。全句谓唯有把这种认知之病当作病来警惕对治，才能不陷于此病。老子由此提出"圣人不病，以其病病"的结论。河上公注："夫唯病病，是以不病。"以"病"为身之患，注文向治身养生引申。成玄英以重玄双遣解之：能病所病，则病无病，遣执而归无执。陈鼓应译为"把这种毛病当作毛病，所以没有毛病"，并指出老子此章是"认识论的自我反省"。楼宇烈强调王弼注老以"崇本息末"为纲，此章之"病病"即去末返本之功。王弼以"无"为本、"崇本息末"，故"病病"是对执著于知见之末的层层消解，归于虚静之本；郭象主"独化"、反对有高于万物的本根，故"病病"不是返本而是"任其性分之自然"，不以己知强加于物；成玄英重玄学以"遣有遣无、遣之又遣"解此，认为"病病"本身亦不可执，最终连"病病"之念亦遣，达于重玄之境；庄子则以"齐物"消解是非对待，主张"两行"与"莫若以明"，其"病病"不是对治而是超越对治，与老子"以病为药"的路径有微妙差异；海德格尔以"无"为存在之遮蔽，主张"泰然任之"（Gelassenheit）式的非对象化思，与老子"病病"相近于一种不断的自我警醒与去蔽，但海氏面向存在史之思，老子面向修身治世之道，问题域不同；王夫之以"气化"言道，认为道在气化日新之中，故"病病"是一种在变动中不断修正的动态工夫，而非静态的返本。

    L2河上公注："夫唯病病，是以不病。"以"病"为身之患，注文向治身养生引申。成玄英以重玄双遣解之：能病所病，则病无病，遣执而归无执。陈鼓应译为"把这种毛病当作毛病，所以没有毛病"，并指出老子此章是"认识论的自我反省"。楼宇烈强调王弼注老以"崇本息末"为纲，此章之"病病"即去末返本之功。
    L3王弼以"无"为本、"崇本息末"，故"病病"是对执著于知见之末的层层消解，归于虚静之本；郭象主"独化"、反对有高于万物的本根，故"病病"不是返本而是"任其性分之自然"，不以己知强加于物；成玄英重玄学以"遣有遣无、遣之又遣"解此，认为"病病"本身亦不可执，最终连"病病"之念亦遣，达于重玄之境；庄子则以"齐物"消解是非对待，主张"两行"与"莫若以明"，其"病病"不是对治而是超越对治，与老子"以病为药"的路径有微妙差异；海德格尔以"无"为存在之遮蔽，主张"泰然任之"（Gelassenheit）式的非对象化思，与老子"病病"相近于一种不断的自我警醒与去蔽，但海氏面向存在史之思，老子面向修身治世之道，问题域不同；王夫之以"气化"言道，认为道在气化日新之中，故"病病"是一种在变动中不断修正的动态工夫，而非静态的返本。
