📜 原文

大道泛兮，其可左右。万物恃之而生而不辞，功成不名有。衣养万物而不为主，常无欲，可名于小；万物归焉而不为主，可名为大。以其终不自为大，故能成其大。

📖 四步导读

《第 34 章》四步导读


①书概览（5 分钟，建立全貌）


这一章讲“道”到底是怎么运作的。老子说大道像水一样四处漫流，万物靠它生长，它却不推辞、不邀功、不占有、不控制。有意思的是，老子用“小”和“大”这对反义词来描摹道：它永远不逞强当主子，看起来“小”；万物却都归向它，这才是真正的“大”。最重要的收获是一句反直觉的智慧——正因为从不自封伟大，反而成就了伟大。这既是对道体的描画，也是一种处世姿态的示范。


②多问题意识关联


  1. 1. 如果你做了事却“功成不名有”，也就是功劳不归自己，长期下来你还愿意继续做事吗？
  2. 2. 如果资源都归向你不等于你要去支配它们，一个“不为主”的管理者或父母，现实中做得到吗？
  3. 3. 如果把“不自为大”当成手段去“成其大”，那它还是不自大吗，还是变成了最高级的自大？

    4. ③其他作者观点碰撞


    • - 韩非：法家恰好反着来。他主张君主必须牢牢握住“二柄”（赏罚），明明白白地“为主”。在老子的“不为主”处，韩非看到的不是美德，而是权力真空的危险。
    • - 王阳明：良知学讲“万物一体之仁”，与“衣养万物”有相通处；但阳明强调“心”要主动承担、感应无隔，而老子强调的却是退一步、不居功、不宰制，两者对“担当”的理解方向不同。
    • - 福柯：福柯对“不为主”的权力叙事高度警惕。在他看来，“不控制、只养育”的话语本身可能就是一种更精细的权力技术——越是宣称无欲无求的治理，越可能把对象纳入更深的规训之中。

    ④精读推荐（小白怎么读这章）


    （1）第一遍（速览）：抓住三个关注点——“大道泛兮，其可左右”写道之无所不在；“功成不名有”“衣养万物而不为主”写道之功成而不居；“常无欲，可名于小；万物归焉而不为主，可名为大”写小大之辨。先感受语气：老子是在描述道，还是在借道说人。


    （2）第二遍（细抠）：两个论证必须看。一是“衣养万物而不为主……可名于小；万物归焉而不为主，可名为大”——同一个“不为主”，前半说它卑下不起眼故“小”，后半说它承载万物归附故“大”，正反两面咬合在一起；二是结尾“以其终不自为大，故能成其大”——这是全章的因果枢纽，要看清“不自为大”是前提、“成其大”是结果，中间不是算计。


    （3）第三遍（思辨）：留一个问题给自己追问——如果“不自为大”真的只是不求大名的自然结果，那它和“以退为进”的权谋术到底差在哪里？你能否从文本里找到证据，说明老子讲的不是策略，而是品格？

    📝 结构化笔记

    章节主旨：本章集中论述道的普遍流行、生成养育万物而不占有、不主宰的品格，并通过“小”与“大”的辩证统一，揭示“不自为大故能成其大”的智慧，是对道体与道用关系的核心说明。

    📌 核心命题

    1. 大道广泛流行，可左可右，无所不在。
    2. 万物依赖道生长，道不推辞。
    3. 道成就万物而不占有功名。
    4. 道养育万物而不做主宰。
    5. 道常无欲可称为小；万物归附而不主宰可称为大。
    6. 正因道始终不自称大，所以能成就其大。

    🔑 关键论据

    1. 大道泛兮，其可左右。
    2. 万物恃之而生而不辞，功成不名有。
    3. 衣养万物而不为主，常无欲，可名于小；万物归焉而不为主，可名为大。
    4. 以其终不自为大，故能成其大。

      术语L0 一句话（普通人能懂）L1 教材级别（中文百科）L2 学术级别（引用原学术语）L3 哲学/思想史反思（不同流派怎么理解）
      大道泛兮，其可左右道像泛滥的河水到处流，左边右边都有它，哪儿都不缺。大道广泛流行、无所不至，可以左右逢源、周流无碍。"泛"形容道如大水漫溢，不局限于一隅。王弼注："言道泛滥，无所不适，可左右上下周旋而用，则无所不至也。"以"泛"训广泛周流，"左右"引申为无所偏倚、无所不至。河上公从养生立说，以道为气、遍行周身，故"可左右"；成玄英重玄学以"泛"为不滞一边、双遣左右，道非有非无而周行；陈鼓应强调此句言道的普遍性与开放性，与《二十五章》"周行而不殆"互训。
      不辞万物靠着道生长，道从不推辞、不嫌麻烦，来者不拒。万物依靠道而生，道从不拒绝、不推辞，任万物自生自长。"辞"即推辞、辞谢。王弼注："万物皆由道而生，既生而不知其所由。"强调道生而不辞、不居其功；河上公训"辞"为"辞谢"，以道不辞谢万物之求。郭象以"独化"解，谓万物块然自生、无待于外，本无所谓道之"辞"与"不辞"，这是对老子生成论的改造；荀子"天行有常，不为尧存，不为桀亡"以天为自然法则，亦不涉"辞"的意志；刘笑敢指出"不辞"体现道"生而不有"的非支配性。
      不有事情做成了，道却不把功劳记在自己头上。道成就万物，却不占有、不居功，功成而弗居。王弼注："功成而不有，故能成其大。"以"无"为体，功成而不自有；苏辙《老子解》以"不有"为不自有其功、不居其名。郭象主张万物独化，功成乃自然之迹，本无"有"与"不有"之对；韩非《解老》以"不有"为不处其功、不争名位，偏向君人南面之术；王夫之以气化言，功成是气之聚散自然，不有即不滞于迹。
      衣养万物道像一件大衣服，把万物都盖住、护着，养着它们。道覆盖、养护万物，如衣之被体。"衣养"即以衣覆养，喻道对万物的庇护与滋养。"衣"读去声，动词，覆盖。河上公注"衣养万物"为道如衣被万物，偏养生解；王弼以"衣养"为道之覆育，与"不为主"连读。河上公、道教内丹以"衣养"为精气覆护周身、温养百骸；成玄英重玄学以"衣养"为养而无养、不滞于养；怀特海过程哲学以万物相互"摄入"（prehension）为养护关系，近于关系性的"养"，但无"衣"的覆盖意象。
      不为主道养着万物，却不把自己当老板、不当万物的主人。道虽覆养万物，却不做万物的主宰，任其自然发展。王弼注："万物归焉而不为主，可名为大。"以"不为主"为道之"无"德；河上公以"不为主"为不宰制、不专制于物。郭象以"独化"反对立"主"，万物各适其性，无主宰者；庄子"齐物"谓道"未始有封"，不立主宰；中观缘起以"无自性"破主宰之执，禅宗"无心"近之；海德格尔以"存在"非存在者之最高主宰，与此有可比性。
      不自为大道从不觉得自己了不起，正因如此，它才真正伟大。道始终不自以为大，所以能成就其大。这是老子的辩证智慧：不自大反而成其大。王弼注："以其终不自为大，故能成其大。"以"无"为体，不自大故能大；苏辙以"不自大"为道之谦德，与"大国者下流"相贯。郭象以"独化"解"自大"为妄立，不自大即任自然；韩非《解老》以"不自大"为君人南面之术，不争而自大；王夫之以气化言，大是自然之量，不自大则无执；海德格尔"泰然任之"（Gelassenheit）近于不自大而让存在者存在，但语境不同。

      L0道从不觉得自己了不起，正因如此，它才真正伟大。
      L1道始终不自以为大，所以能成就其大。这是老子的辩证智慧：不自大反而成其大。
      L2王弼注："以其终不自为大，故能成其大。"以"无"为体，不自大故能大；苏辙以"不自大"为道之谦德，与"大国者下流"相贯。
      L3郭象以"独化"解"自大"为妄立，不自大即任自然；韩非《解老》以"不自大"为君人南面之术，不争而自大；王夫之以气化言，大是自然之量，不自大则无执；海德格尔"泰然任之"（Gelassenheit）近于不自大而让存在者存在，但语境不同。
