📜 原文

善行无辙迹，善言无瑕谪；善数不用筹策；善闭无关楗而不可开，善结无绳约而不可解。是以圣人常善救人，故无弃人；常善救物，故无弃物，是谓袭明。故善人者，不善人之师；不善人者，善人之资。不贵其师，不爱其资，虽智大迷，是谓要妙。

📖 四步导读

《第 27 章》四步导读


①书概览（5 分钟，建立全貌）

本章描绘了一种“不留痕迹的高明”：最好的行动没有轨迹，最好的言辞没有破绽，最好的关闭不用门闩却打不开。老子由此推出一条出人意料的伦理结论——真正的圣人从不抛弃任何人，因为他总能把人“救”到合适的位置上。最有趣的是结尾那组悖论：好人是不好人的老师，不好人是好人的资本；不珍惜这层关系，再聪明也是大糊涂。你最重要的收获是：善与不善并非对立淘汰，而是互为资源。

②多问题意识关联

1. 如果你做完一件事，没人能指出你“做了什么”，这算成功还是失败？
2. 如果一个人处处是缺点，社会却声称“没有废人”，这靠什么成立？
3. 如果你拒绝向不如你的人学习，你失去的究竟是面子还是“资借”？

③其他作者观点碰撞

维特根斯坦：语言的界限即世界的界限——老子说“善言无瑕谪”，恰似维氏所言真正要紧的东西往往不可言说，说清楚的反而露破绽。
福柯：权力最有效的运作不是压迫而是“不留痕迹”的规训——可与“善闭无关楗而不可开”对读，无痕的控制才最难挣脱。
王阳明：知行合一，善是良知自然流行，不假安排造作——正合“善行无辙迹”的无所为而为。
荀子：人之性恶，善者伪也，须师法教化——他会质疑老子“无弃人”是否低估了教化所需的制度痕迹。

④精读推荐（小白怎么读这章）

（1）第一遍（速览）：关注三处——① 五个“善”字句的排比节奏，感受老子如何用“不用工具”定义高明；② 从“善行”到“善救人”的跳跃，看技巧如何转为伦理；③ 结尾“师”与“资”的对举，抓住全章枢纽。

>

（2）第二遍（细抠）：必看两个论证——其一，“圣人常善救人，故无弃人”的推理：救人不是施舍，而是把人放回可用的位置，这才叫“袭明”；其二，“不善人者，善人之资”——不善者不是被淘汰的对象，而是善者反省与改进的凭借，没了“资”，善也无从成立。

>

（3）第三遍（思辨）：追问——如果“无弃人”成立，那“不善人”究竟是尚未被救的人，还是永远作为“资”而存在的人？一个永远需要“不善”来定义的“善”，是否陷入了老子自己也没解开的循环？

📝 结构化笔记

章节主旨：本章以“善行、善言、善数、善闭、善结”说明无为而善的境界，进而提出圣人无弃人弃物的“袭明”，并论述善人与不善人的师资关系，强调不贵师、不爱资的“要妙”。

📌 核心命题

  1. 善行不留辙迹，善言没有可指责的瑕疵。
  2. 善数不用筹策，善闭不用关楗而不可开，善结不用绳约而不可解。
  3. 圣人常善救人，所以无弃人；常善救物，所以无弃物，这称为袭明。
  4. 善人是不善人的老师，不善人是善人的资借。
  5. 不贵其师、不爱其资，虽自以为智也是大迷，这称为要妙。

🔑 关键论据

  1. 善行无辙迹，善言无瑕谪；善数不用筹策；善闭无关楗而不可开，善结无绳约而不可解。
  2. 是以圣人常善救人，故无弃人；常善救物，故无弃物，是谓袭明。
  3. 故善人者，不善人之师；不善人者，善人之资。
  4. 不贵其师，不爱其资，虽智大迷，是谓要妙。

    📚 术语表（L0-L3）

    L0 一句话 / L1 教材级 / L2 学术级 / L3 哲学反思

    术语L0 一句话（普通人能懂）L1 教材级别（中文百科）L2 学术级别（引用原学术语）L3 哲学/思想史反思（不同流派怎么理解）
    善行无辙迹真正会做事的人，做完不留下张扬的痕迹。老子以车辙比喻人为造作的痕迹；“善行”指合道之行，“无辙迹”即不炫耀、不留下可执著的痕迹，重在无为而自然。原文作“善行无辙迹”。“辙迹”为车行痕迹，引申为造作、形名、可循之迹。王弼注以“顺自然而行，不造不始”释之，属于“因物之性”的无为。王弼以“无”为本，注此句强调“顺自然而行，不造不始”，善行不是立规矩留痕迹；郭象在《庄子注》中主“独化”，认为万物自生自化，圣人任物自尔，故不须以形迹规范；海德格尔讲“无”与存在之遮蔽，可对照老子不落痕迹的“行”不是虚无，而是让存在者如其本然地显现。
    善言无瑕谪会说话的人，话里挑不出毛病。善言者不逞辩、不伤人，言合于理，故无可指摘。原文作“善言无瑕谪”。“瑕”为玉病，“谪”为谴责、过失。王弼注谓“顺物之性，不别不析”，不以名言剖析强加于物。王弼以“无”为本，释善言为顺物之性、不别不析；苏辙《老子解》常以“无心”解老，认为圣人无心而应，故言不著痕迹、无可瑕谪；维特根斯坦论语言界限，认为许多东西不可言说、只可显示，可与“善言”不落言筌相参。
    善数不用筹策真正会算的人，不用摆算筹也算得准。善数者以心契理，不依赖外在计算工具；喻合道者不假人为筹度。原文作“善数不用筹策”。“筹策”为古代计数竹木。王弼注“因物之数，不假形也”，即以物之自然数为数，不以形器强算。王弼注“因物之数，不假形”，以无为本，反对以形名筹度万物；河上公注偏治身治国，以“善数以心，不用筹策”为说，重在省事养生；怀特海过程哲学强调关系内在，可与“不假筹策”的契入式理解相参照。
    善闭无关楗而不可开真正会关门的人，不用门闩别人也打不开。善闭者不在门闩等形制上用力，而使人自然不能开；喻以道守御，不靠外在强制。原文作“善闭无关楗而不可开”。“关楗”即门闩。王弼注“因物自然，不设不施”，故不用关楗而不可开。王弼以“不设不施”释善闭，认为因物自然则无须形制；成玄英重玄学主张遣有遣无，连“闭”与“不闭”之迹亦遣，故不可开；韩非《解老》强调“缘道理以从事”，法家由此可把不待关楗理解为不恃形制而恃法势。
    善结无绳约而不可解真正会打结的人，不用绳子别人也解不开。善结者不以绳索约束，而使人自然相合不可解；喻以道相结，不靠外在约束。原文作“善结无绳约而不可解”。“绳约”即绳索约束。王弼注“因物自然，不设不施”，不用关楗绳约而不可开解。王弼以“因物自然，不设不施”释善结；郭象“独化”论可通，万物自得自尔，不需外在绳约而自相固结；禅宗讲“无心”而行，不著系缚之相，故无绳约而不可解。
    袭明圣人善于救人救物、不抛弃人和物，这叫承袭明道。“袭”为因袭、承袭；“明”指道之明。圣人常善救人救物，无弃人弃物，是承袭道之明。原文作“是谓袭明”。王弼注“袭，犹因也”，即因顺自然之明，不立形名以检物。陈鼓应《老子今注今译》解为“承袭明道”、因顺自然。王弼注“袭，犹因也”，以无为本，重因顺；河上公注从治身治国讲圣人救人救物，使各得其所；苏辙以“无心”解圣人不弃人弃物，明非外在之智，而是无心而照。
    善人者，不善人之师好人可以给不好的人当老师。善人可作不善人的榜样和老师，不善人可因之而改。原文作“善人者，不善人之师”。“师”为师范、师法。老子随即说“不贵其师”，即虽为师而不执师相。王弼注以“因”释之，善人所以为师在不立形名、不弃不善；庄子《齐物论》讲“彼是相因”“道枢”，善与不善相待而通，师资之别亦非绝对；孔子说“三人行，必有我师焉”，重师法，老子则“不贵其师”，不执师相，二者可对照。
    不善人者，善人之资不好的人也可以成为好人的借鉴和资源。不善人可作善人的资借、镜鉴，使善人知所戒惧、有所成就。原文作“不善人者，善人之资”。“资”为资借、凭借。老子说“不爱其资”，即不弃不善而善用之。王弼以因顺释之，善人不弃不善，反以之为资；庄子齐物讲“两行”不废是非，不善亦在相待中成其用；荀子说“见不善，愀然必以自省也”，以不善为修身之鉴，可与老子“资”义相参。
    要妙不贵师、不爱资这个道理，看似简单，其实很精微。“要妙”指精要微妙之理；老子认为不执师资之别、善用一切，是道的要妙。原文作“是谓要妙”。“要”为切要，“妙”为微奥。王弼注以“因”释之，不贵不爱的关键在因顺自然、不立形名。王弼以“无”为本，认为要妙不在智巧，而在因物自然；成玄英重玄学双遣师资、有无，连“要妙”亦不滞，方为真要妙；维特根斯坦言语言界限，可说者清楚、不可说者沉默，与老子“要妙”不可尽以名言尽之相参。
