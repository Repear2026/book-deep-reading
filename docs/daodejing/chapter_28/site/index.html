📜 原文

知其雄，守其雌，为天下溪。为天下溪，常德不离，复归于婴儿。知其白，守其黑，为天下式。为天下式，常德不忒，复归于无极。知其荣，守其辱，为天下谷，常德乃足，复归于朴。朴散则为器，圣人用之，则为官长，故大制不割。

📖 四步导读

《第 28 章》四步导读


①书概览（5 分钟，建立全貌）

这一章讲一种“反向修养”：明明知道什么是雄强、显白、荣耀，却主动选择安守雌柔、暗昧、卑辱。老子认为这样做不是软弱，而是让自己成为“天下溪”“天下式”“天下谷”——像溪谷一样能容纳、能汇聚，从而让“常德”不离、不忒、充足，最终回到婴儿般的原初状态、无极般的开放状态、朴一样的未雕状态。最后一句“朴散则为器，圣人用之则为官长，故大制不割”把修养论一转身变成政治论：真朴一旦散开为具体器用，圣人能善加统御而不切割它的整体。全章最有趣的收获是：“知”与“守”不是认识论上的知道，而是一种主动的自我降位的生存姿态。

②多问题意识关联

1. 如果你明明看穿了某场竞争的所有规则和优势，却选择不争，这是智慧还是逃避？
2. 如果社会奖励“表现得聪明、光鲜、强势”，你主动藏起锋芒，会不会反而失去机会？
3. 如果一套制度非要把人“归类”“切割”成可管理的零件，你还能守住自己不被打散的完整性吗？

③其他作者观点碰撞

- 王阳明：提出“无善无恶心之体”，认为心的本体超越善恶对立。老子“知雄守雌”的努力，在阳明看来可能仍停留在“知”上做工夫；阳明更强调在“事上磨”直接呈现良知本体，而非刻意守一个“雌”的姿态。
- 荀子：主张“化性起伪”，认为人性本朴但必须通过礼义师法来“文”化、“分”化。老子讲“复归于朴”“大制不割”，荀子则会反问：不切割、不雕琢，人如何成器？礼义正是要“断长续短”、把人从自然质朴引向文明秩序。
- 福柯：对“大制不割”构成强烈反讽。福柯在《规训与惩罚》中揭示，现代制度恰恰靠“分割空间、切分时间、分类人群”来运作——学校、医院、监狱都在“割”中生产秩序。老子的“不割”在福柯眼里几乎是一种不可能的政治想象，但正因不可能，才构成对现代治理逻辑的尖锐批判。
- 维特根斯坦（可选补充）：“知白守黑”的“知”若按后期维特根斯坦看，不是命题性的知识，而是嵌入生活形式的实践能力——知道白是什么，意味着会使用“白”这个词、会区分明暗；守黑则是在语言游戏的边界处保持沉默。这与老子“知而不守”的张力可互为参照。

④精读推荐（小白怎么读这章）


（1）第一遍（速览）：三个关注点
- 注意三组排比的结构：每组的“知X”和“守Y”是反向的（雄/雌、白/黑、荣/辱），而“为天下溪/式/谷”是守之后的结果。
- 关注三组“复归”的不同终点：婴儿（生命原初态）、无极（空间与价值的无边界态）、朴（材质未雕态）——三者不是同义反复，而是从个体生命到宇宙秩序到政治材质的层层递进。
- 最后一句突然从修养转到“器”和“官长”：这是全章结构的转折点，要留意“朴散”是被动还是主动、“用之”是谁在用。

（2）第二遍（细抠）：两个必看的论证
- 论证一（修养论）：为什么“守雌”能“为天下溪”？关键在溪的意象——溪是低处，水往低处流，所以溪能汇聚。老子用地理比喻完成了一个逻辑转换：主动处于卑下位置，反而获得汇聚天下的能力。要盯住“常德不离”这个结果——德不是靠“知”获得的，而是靠“守”保持在身上的。
- 论证二（政治论）：“朴散则为器，圣人用之则为官长，故大制不割”是全章最难的一句。需要弄清三个层次：朴（未分化的整体）→器（分化的具体功用）→官长（圣人统御器物的人事安排）。老子的难点在于：既然“散”已经发生，如何还能说“不割”？可能的理解是：圣人“用”器时不让器反过来割裂人，即用而不执、分而不裂。

（3）第三遍（思辨）：一个该追问的开放问题
- “知雄守雌”是否要求人真的具备“雄”的能力和知识？ 如果一个人根本不知雄为何物，只是天然地柔软退让，这算不算“守雌”？还是说，老子的“守”必须建立在“知”的基础上，才算一种有意识的修炼而非本能？进一步问：这种“知而不为”的姿态，与福柯所说的自我技术（有意识地塑造自身）有多少可比性？老子是否在教人修炼一种“反向的权力姿态”——恰恰通过不争、不显、不居功来获得最大的影响力和稳定性？

📝 结构化笔记

章节主旨：本章论述“知—守”相成的修养与治理原则：在知雄、知白、知荣的同时守雌、守黑、守辱，以成就天下溪、天下式、天下谷，使常德不离、不忒、充足而复归婴儿、无极、朴；并由“朴散为器”引出圣人用器为官长、大制不割的政治秩序观。

📌 核心命题

  1. 知雄守雌可成为天下溪，使常德不离而复归婴儿。
  2. 知白守黑可成为天下式，使常德不忒而复归无极。
  3. 知荣守辱可成为天下谷，使常德充足而复归朴。
  4. 朴散为器，圣人用之则为官长，大制不割。

❓ 我的错题本

    📚 术语表（L0-L3）

    L0 一句话 / L1 教材级 / L2 学术级 / L3 哲学反思

    术语L0 一句话（普通人能懂）L1 教材级别（中文百科）L2 学术级别（引用原学术语）L3 哲学/思想史反思（不同流派怎么理解）
    天下溪像山谷里的溪水一样，甘愿处在天下最低处，让众流归向自己。语出《老子》第二十八章"知其雄，守其雌，为天下溪"。溪为山间低洼水道，众水所归。老子以溪喻圣人守柔处下、不争而容纳天下。河上公注："雄以喻尊，雌以喻卑。人虽知自尊显，当复守之以卑微，去雄之强梁，就雌之柔和，如是则天下归之，如水流入深溪也。" 王弼注以"雄雌"为"好恶"之喻，主张"知为天下之先，守为天下之后"。河上公从养生与治身角度读"溪"为虚心纳气之所；王弼以贵无论解为"不争而物自归"，强调守母存子；成玄英重玄学则解为遣除雄雌二边之执，双遣双非方为真守。
    常德不会流失、不会偏离的根本德性。"常德"指恒常不易之德，与"常道"相应。二十八章三言"常德"，分别为"常德不离""常德不忒""常德乃足"，对应溪、式、谷三种守柔形态。王弼《老子注》："常德不差忒，乃反归于朴。" 苏辙《老子解》以"常"为"无方而无不在"，谓德至于常则不复失。王弼以"常"为得道之恒，德是道在具体处的滞留；郭象注《庄》式的思路则否认有一恒常之"德"悬于物上，主张德即各物自得之性；儒家（如朱熹）批评老子的"常德"只是"守得一个不生不长的物事"，缺却人伦日用之实。
    婴儿回到像初生婴儿那样柔软、未受污染的状态。《老子》屡以"婴儿"喻德全之状（十章"专气致柔，能婴儿乎"、二十章"如婴儿之未孩"）。二十八章"复归于婴儿"指由守雌守柔而复归本真。河上公注："儿无常父，衣无常主"，以婴儿喻无分别、无执著。王弼注："婴儿不用智，而合自然之智。"河上公与道教内丹家从"返本还元"解婴儿，视之为炼精化气、复归先天之象；王弼从"不用智"解，近于无心而合自然；庄子"心斋坐忘"一路则以婴儿喻"吾丧我"后的无待之境，与老子侧重不同。
    天下式成为天下人效法取正的样板、法式。"式"通"栻"，古代占卜用的工具，引申为法式、准则。二十八章"为天下式"，谓圣人守柔不争，遂为天下所取法。王弼注："式，模则也。" 河上公注："式，法也。人能为天下法式，则德常在于己，不复差忒也。"儒家解"式"为"表正万邦"的德范，但强调须以礼乐教化充实之，荀子所谓"君者，仪也，仪正而景正"；法家韩非则将"式"读为"法式"之"式"，主张"不务德而务法"，与老子守柔之式分途；王弼则纯以"不争而天下自正"为式之内涵。
    无极没有尽头、没有边界，回到不可穷尽的本源。二十八章"复归于无极"，指复归于道之无穷无尽、无有端倪。"无极"一词后为宋明理学（周敦颐《太极图说》"无极而太极"）所大用。河上公注："无极，谓空虚，无有极尽之时。" 王弼注以"无极"为"不可穷也"，与"朴"相贯。宋儒周敦颐、朱熹以"无极而太极"建立宇宙论，把无极纳入儒家形上学，与老子原义已有距离；王弼以"无"为无极之实，郭象则根本否认有一个"无极"的本源可归，主张"物各自造而无所待"；佛教中观则以"无自性"释无极，不许立一实体之源。
