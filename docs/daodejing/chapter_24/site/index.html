📖 四步导读

《第 24 章》四步导读


①书概览（5 分钟，建立全貌）

这一章很短，却像一面照妖镜：踮脚想站得更高的人，反而站不稳；跨大步想跑得更快的人，反而走不远。老子把身体上的“用力过猛”直接搬到做人做事上——“自见、自是、自伐、自矜”四种姿态，结果分别是“不明、不彰、无功、不长”。最后一句最狠：这些在“道”看来不过是“余食赘行”（剩饭、赘瘤），万物都厌恶，所以有道者不这么待着。最重要的收获：越想靠“加码”证明自己，越容易失去自己；真正的稳，来自不额外多使一分劲。

②多问题意识关联

- 如果你在会议上拼命抢着表现“这主意是我想的”，别人对你的印象会变好，还是反而变淡？
- 如果一条朋友圈你反复修饰、力求显得“毫不费力”，那种用力本身会被看出来吗？
- 如果把“踮脚跟”换成一个组织拼命冲业绩、一个人拼命加班刷存在感：短期看似高了，长期它会失掉什么？

③其他作者观点碰撞

- 孟子（揠苗助长）：宋人嫌禾苗长得慢，把它往上拔，结果苗全枯了。老子讲“企者不立”，孟子讲“拔苗者不苗”，都在说同一件事：超出自然节律的“加速”，其实是一种自毁。
- 荀子（《劝学》）：却说“不积跬步，无以至千里”——看似和“跨者不行”相近，但荀子的话更重，也更积极：他强调的是“积累”而非“跨越”，正可与老子互补，一个戒“跳“，一个劝“走”。
- 亚里士多德（中道说）：他在《尼各马可伦理学》里主张德性存在于“过度与不足之间”。“自矜”就是“过度”一端的典型：对自己的评价超出了实际，于是偏离了德性，这与老子“自伐者无功”是同一个诊断，只是亚里士多德给出了“应该取其中道”这一解法，老子则主张“不处”（直接退出来，不站进这个位置）。
- 王弼（《老子注》）：他把“余食”解作“盛馔之余”（吃饱后多出来的饭），把“赘行”解作形体上的赘瘤——都是“本不属于身体、却硬长在身上”的东西。这个注解提醒我们：老子反对的不是“做事”，而是那种“多余出来的自我展示”。
- 韩非（《解老》《喻老》）：作为现存最早系统解老的人之一，他常把这类句子读成“治国之术”——君主若事事自逞己见，臣下就无从进言，于是“不明”。同一个句子的政治读法，与修身读法并行不悖。
- 欧文·戈夫曼（拟剧论）：他在《日常生活中的自我呈现》里指出，人在“前台”刻意经营形象时，一旦表演失控（“露怯”），观众立刻会怀疑整个表演的真实性。这几乎就是“自见者不明”的现代社会学版本：越是忙着展示，越容易被看穿。

④精读推荐（小白怎么读这章）

（1）第一遍（速览）：三个关注点
① 看开头两个比喻——“企”和“跨”，都是“身体想超越自身限度”；② 看中间四个“自×者不×”，注意它们是一一对应的，不是随手排比；③ 看结尾的“余食赘行”，这是全章唯一一个“比喻中的比喻”，也是最费解的地方，先记下来。

>

（2）第二遍（细抠）：两个必看的论证
① “企者不立，跨者不行”是类比，不是证明：老子没有说“为什么”，他只是让你在身体经验里自行验证——踮脚三十秒你就懂了。这个“以身体喻道理”的手法，是全书的通用方法，值得留意它什么时候生效、什么时候不生效。
② “其在道也，曰余食赘行。物或恶之，故有道者不处”：注意“或”字（“或许”“有的”），老子说得并不断然；“不处”也不是“消灭它”，而是“不让自己待在那个位置上”——是一种姿态上的回避，不是道德上的讨伐。

>

（3）第三遍（思辨）：一个该追问的开放问题
如果“自见、自是、自伐、自矜”都该戒，那么一个人要如何“被看见”？老子的答案似乎是“不自见故明”（第 22 章），可这句话本身是不是也要被“看见”？——换句话说：“不自我夸耀”这件事，会不会变成一种更高级的自我夸耀？ 这正是后世注家与禅门反复纠缠的难题，也是你读这一章最该带走的问题。

📝 结构化笔记

章节主旨：本章从反面立论，以“企者”“跨者”为喻，说明刻意强求、自逞自夸违背自然之道；并通过“自见、自是、自伐、自矜”的否定性判断，警示有道者不应处身于“余食赘行”之中。

📌 核心命题

  1. 踮起脚跟想站得高的人反而站不稳，跨大步想走得快的人反而走不远。
  2. 自逞己见、自以为是、自我夸耀、自矜自大的人，分别不能明、不能彰、无功、不长。
  3. 从道的角度看，上述行为是余食赘行，万物或许厌恶它们，所以有道者不处。

🔑 关键论据

  1. 企者不立，跨者不行。
  2. 自见者不明，自是者不彰，自伐者无功，自矜者不长。
  3. 其在道也，曰余食赘行。物或恶之，故有道者不处。

💡 新概念

企者不立
踮起脚跟想站得高，反而不能久立。
跨者不行
跨大步想走快，反而不能远行。
余食赘行
多余的食物和赘瘤般的行止，比喻道所厌恶的多余行为。

  • 可与《道德经》中“功成身退”“不居”等思想关联，理解有道者不处余食赘行的态度。

    📚 术语表（L0-L3）

    L0 一句话 / L1 教材级 / L2 学术级 / L3 哲学反思

    术语L0 一句话（普通人能懂）L1 教材级别（中文百科）L2 学术级别（引用原学术语）L3 哲学/思想史反思（不同流派怎么理解）
    企者不立踮着脚尖想站得高一点，结果反而站不稳、站不久。语出《老子》第二十四章。"企"通"跂"，即踮起脚跟。老子以踮脚求高、跨步求速为喻，说明一切超越常度、刻意造作的行为都不能持久，是"自见、自是、自伐、自矜"一类彰著之心的反面例证。《说文》："企，举踵也。"王弼注："物尚进则失安，故曰企者不立。"河上公注："企，进也。跂足，立功名也。"此句与下句"跨者不行"对文，并与"自见者不明，自是者不彰，自伐者无功，自矜者不长"连读，构成一组反面列举，落点为"其在道也，曰余食赘行"。王弼以"贵无"为纲，把"企"读作"尚进"，认为执着于有所作为（进）反而脱离本体之"无"而"失安"；河上公从养生角度把"跂足立功名"解为向外驰逐、伤其自然之性；郭象注《庄》主"独化"与"性分"，可延伸理解为刻意为"立"定一个统一的固定姿态，本身就越出了个体自性之分量；成玄英的重玄学则连"企"与"不立"两边一并双遣，不落取舍。现代陈鼓应把此章视为老子对"自见、自是、自伐、自矜"的进一步申说，归旨于"自然无为"。
    跨者不行一步跨得太大想走快，反而走不了远路。语出《老子》第二十四章，紧承"企者不立"。"跨"即越过、跨大步，引申为急躁冒进、逾越常度。老子指出：越想速成、越想超过常轨，越到不了远处，与"企者不立"同为一组"反常合道"的反面例证。《说文》："跨，渡也。"王弼注："行不远也。"河上公注："跨，越也……其行不久也。"此句与"企者不立"在句式、语义上完全对文，是《老子》书中"反者道之动"辩证表述的典型句法："欲速则不达"，以反显正。王弼从"贵无"出发，释"跨"为"尚疾"而"失全"，急躁造作不能致远；河上公从养生修炼立论，认为跨越常度则伤其形、耗其气；郭象的"独化"论强调万物各安性分、各当其分，"跨"是越过自家性分之事，故不能行远；韩非《解老》以"理"释"道"，认为"跨"违背事物之"理"，理不顺则行不成。现代刘笑敢指出，此章以"反"的辩证法表达"过犹不及"，与儒家中庸之"过犹不及"命题可参看而理路不同：老子归于"道"的自然，孔子归于"礼"的中节。
    余食赘行剩饭和身上多余的瘤子，比喻那些多出来、招人讨厌的造作之举。语出《老子》第二十四章："其在道也，曰余食赘行，物或恶之，故有道者不处。""余食"即剩饭，"赘行"即赘瘤般的行止。老子以此总收上文"企者不立、跨者不行、自见、自是、自伐、自矜"诸项，说明一切超出自然本分、由有意造作而生的行为，都是道所厌弃的多余之物。河上公注："赘，附也……若附赘悬疣，此非自然之道也。"王弼注："其唯于道而论之，若郄至之行，盛馔之余也。犹剩也。"王弼以《左传》成公十六年郄至恃勇自夸而取祸的旧事为"赘行"之证，以"盛馔之余"训"余食"，并申明"故有道者不处"——不处即不居、不据。河上公以养生家言释"赘"为附赘悬疣，主张去其多余、复归自然之形；王弼以"无"为本，视"余食赘行"为出于造作、溢出本体之"无"的剩余，故须"不处"；郭象在《庄子注》中主"性分"说，把超出本分的多余之举比作"骈拇枝指"，是"侈于德"而非"出于德"；苏辙《老子解》以"道出于自然"立论，认为"余"与"赘"皆非自然之常。可对照佛学中观：以"缘起性空"观之，凡增益自性之执皆为戏论；亦可对照海德格尔，但老子此语是从生成论与否定辩证法的角度提出的"去除多余"，与海德格尔"存在之遮蔽"的现象学路径不同。

    跨者不行

    L0一步跨得太大想走快，反而走不了远路。
    L1语出《老子》第二十四章，紧承"企者不立"。"跨"即越过、跨大步，引申为急躁冒进、逾越常度。老子指出：越想速成、越想超过常轨，越到不了远处，与"企者不立"同为一组"反常合道"的反面例证。
    L2《说文》："跨，渡也。"王弼注："行不远也。"河上公注："跨，越也……其行不久也。"此句与"企者不立"在句式、语义上完全对文，是《老子》书中"反者道之动"辩证表述的典型句法："欲速则不达"，以反显正。
    L3王弼从"贵无"出发，释"跨"为"尚疾"而"失全"，急躁造作不能致远；河上公从养生修炼立论，认为跨越常度则伤其形、耗其气；郭象的"独化"论强调万物各安性分、各当其分，"跨"是越过自家性分之事，故不能行远；韩非《解老》以"理"释"道"，认为"跨"违背事物之"理"，理不顺则行不成。现代刘笑敢指出，此章以"反"的辩证法表达"过犹不及"，与儒家中庸之"过犹不及"命题可参看而理路不同：老子归于"道"的自然，孔子归于"礼"的中节。

    余食赘行

    L0剩饭和身上多余的瘤子，比喻那些多出来、招人讨厌的造作之举。
    L1语出《老子》第二十四章："其在道也，曰余食赘行，物或恶之，故有道者不处。""余食"即剩饭，"赘行"即赘瘤般的行止。老子以此总收上文"企者不立、跨者不行、自见、自是、自伐、自矜"诸项，说明一切超出自然本分、由有意造作而生的行为，都是道所厌弃的多余之物。
    L2河上公注："赘，附也……若附赘悬疣，此非自然之道也。"王弼注："其唯于道而论之，若郄至之行，盛馔之余也。犹剩也。"王弼以《左传》成公十六年郄至恃勇自夸而取祸的旧事为"赘行"之证，以"盛馔之余"训"余食"，并申明"故有道者不处"——不处即不居、不据。
    L3河上公以养生家言释"赘"为附赘悬疣，主张去其多余、复归自然之形；王弼以"无"为本，视"余食赘行"为出于造作、溢出本体之"无"的剩余，故须"不处"；郭象在《庄子注》中主"性分"说，把超出本分的多余之举比作"骈拇枝指"，是"侈于德"而非"出于德"；苏辙《老子解》以"道出于自然"立论，认为"余"与"赘"皆非自然之常。可对照佛学中观：以"缘起性空"观之，凡增益自性之执皆为戏论；亦可对照海德格尔，但老子此语是从生成论与否定辩证法的角度提出的"去除多余"，与海德格尔"存在之遮蔽"的现象学路径不同。
