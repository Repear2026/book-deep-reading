📖 四步导读

《第 72 章》四步导读


①书概览（5 分钟，建立全貌）

这一章老子把镜头对准统治者的威压与百姓的生存底线。当百姓被逼到不再惧怕威慑时，更大的祸患就来了。老子提醒当权者：别挤压百姓的居所，别厌弃他们的生计；只有不厌弃百姓，才不会被百姓厌弃。落到个人修养上，圣人“自知不自见，自爱不自贵”，在炫耀与自贵之间主动舍弃，选取内敛的自知与自爱。最重要的收获是：威压的极限不是服从，而是反弹；真正的保全之道是“去彼取此”。

②多问题意识关联

1. 如果你被不断施压直到“反正也没什么可失去”，你会更服从，还是更可能做出不计后果的反应？
2. 如果一个管理者只会收紧空间、掐断生计来逼人听话，他最终得到的是秩序，还是积压的对抗？
3. 如果你明明有本事却刻意不表现、明明珍重自己却不摆高姿态，别人会低估你，还是会更难撼动你？

③其他作者观点碰撞

- 福柯：权力不只是压制，更是生产性的网络；但福柯也提醒，当权力过度逼近身体与生存条件时，会激发抵抗——可与“民不畏威，大威至矣”对读。
- 荀子：主张“君者，舟也；庶人者，水也”，水能载舟亦能覆舟，与老子“不厌则不被厌”的相互性相通，但荀子更强调礼法制度化。
- 韩非：认为威势是君主治理的核心工具，主张“势”不可失；老子则指出威压用到极致会反噬，二者构成“威”的两种治理逻辑。
- 罗素：在《权力论》中分析对权力的欲望与制约，指出不受限制的权力趋于膨胀并引发反抗，可作现代政治学注脚。

④精读推荐（小白怎么读这章）

（1）第一遍（速览）：关注三个点——①“民不畏威，大威至矣”的因果方向（谁对谁构成威胁）；②“无狭其所居，无厌其所生”的两个“无”针对什么；③最后“自知/自见”“自爱/自贵”的对照结构。

>

（2）第二遍（细抠）：必看两个论证——“夫唯不厌，是以不厌”的相互性逻辑（不厌弃百姓→不被百姓厌弃）；“去彼取此”的取舍结构（舍弃自见、自贵，选取自知、自爱），注意老子不是否定“自知”和“自爱”，而是否定其外显与自高形态。

>

（3）第三遍（思辨）：一个开放问题——“民不畏威”究竟是被压迫到极点的被动反应，还是老子所肯定的一种有边界的抵抗？如果圣人“自知不自见”，那统治者如何在不施威压的前提下维持秩序？这个问题可留到第 73 章继续追问。

📝 结构化笔记

章节主旨：本章从统治者施加威压与百姓生存处境的关系切入，指出过度压迫会招致更大祸患；进而提出圣人应自知、自爱而不自见、自贵，并在二者之间“去彼取此”。

📌 核心命题

  1. 百姓不畏惧威压，巨大的威胁就会到来。
  2. 不要使百姓的居所狭窄，不要厌弃百姓的生计。
  3. 只有不厌弃百姓，才不会被百姓厌弃。
  4. 圣人自知却不自我表现，自爱却不自以为高贵。
  5. 因此舍弃自我表现与自贵，采取自知与自爱。

🔑 关键论据

  1. 民不畏威，大威至矣。
  2. 无狭其所居，无厌其所生。
  3. 夫唯不厌，是以不厌。
  4. 是以圣人自知不自见；自爱不自贵。
  5. 故去彼取此。

    📚 术语表（L0-L3）

    L0 一句话 / L1 教材级 / L2 学术级 / L3 哲学反思

    术语L0 一句话（普通人能懂）L1 教材级别（中文百科）L2 学术级别（引用原学术语）L3 哲学/思想史反思（不同流派怎么理解）
    威（民不畏威）统治者施加的高压威慑，逼得百姓喘不过气。指统治者以刑罚、政令施于民上的威压之势。《老子》此章以“民不畏威”起论，指出威压一旦超出民力承受的限度，威慑本身即告失效。帛书甲乙本、王弼本皆作“民不畏威，则大威至”。王弼注：“威，畏也。”以“威”为可畏之势；河上公注则将此“威”解为“刑威”，与养生、治国之道相连。陈鼓应训“威”为“威压”，译为“人民不畏惧统治者的威压”。王弼以“无”为本，主张统治者“不以威加民”，威压属于“有为”之迹，与无为而治相悖；韩非则从法家立场肯定“威”为君之二柄（刑德）之一，认为威势正是治国所必需，与老子此处对威压的警惕正相对立；苏辙《老子解》以“威”为末，谓民已不畏则威穷而乱生。
    大威百姓一旦不再害怕威压，更大的祸乱或灾殃就会到来。指百姓对威压失去畏惧后所招致的更大祸患，历代注家多解为“祸乱之大者”，亦有人解为“天威”“刑威之极”。王弼注：“威不能制，则大威至矣。”以“大威”为威之极致、威穷而反；河上公以“大威”为“祸罚”；成玄英疏以重玄义解为“大威之至，莫过于死”。陈鼓应译为“可怕的祸乱就要到来”。河上公、道教养生一路把“大威”读作身国同构中的灾殃，偏重治身；王夫之《老子衍》从气化治乱着眼，谓威穷则民散、大乱随之，重在社会政治之势；韩非一系则会把“大威”理解为君权失驭后的刑赏失序，与老子“不尚威”的告诫形成张力。
    无狎其所居不要逼迫百姓的居所，使他们住得局促不安。“狎”通“狭”，作动词用，谓使之狭窄、逼迫。此句意为统治者不应侵扰、压缩百姓的生存居所。帛书乙本作“毋狎其所居”，王弼本作“无狎其所居”。王弼注：“狎，近也。”一说“狎”为“狭”之借字，河上公本即作“狭”。陈鼓应取“狭”义，译“不要逼迫人民的居所”。河上公以“所居”为身中之神室，主张治身者不使精神局促，是养生化的读法；王弼以“无”为本，将“所居”解为万物自得之所，反对以有为侵夺其自然之分；郭象“独化”说可相呼应——各安其性分，不须外力安排其居处。
    无厌其所生不要压榨百姓赖以活命的生活来源。“厌”读作“压”，意为压迫、厌弃。此句谓统治者不应摧残、堵塞百姓的生存之道。王弼本作“无厌其所生”，王弼注：“厌，塞也。”河上公注“厌”为“压”。陈鼓应译“不要压榨人民的生产”，并引“厌”与“压”古通之说。河上公从治身立论，谓“所生”即精气，厌之则神疲，属养生内修一路；王弼以“生”为自然之性分，厌塞之则违“无为之本”；儒家孟子“制民之产”与“无恒产者无恒心”之说与此章“不厌所生”在治理关怀上相通，但孟子立足仁义之政，老子立足不扰之政，进路不同。
    自知不自见有自知之明，却不自我炫耀、不处处表现自己。谓人应有内在的明察而不外露张扬。“自见”读作“自现”，即自我表现、自炫。王弼本作“是以圣人自知不自见”。王弼注：“自知，则无自见也。”陈鼓应译“有自知之明而不自我炫耀”。此句与第二十四章“自见者不明”互文。王弼以“无”为本，认为“自见”是执有之迹，“自知”则返本；成玄英以重玄双遣解之，既不执自见，亦不滞自知，遣之又遣；庄子“至人无己”与“吾丧我”可相参照，但庄子落实于齐物逍遥，老子此章落在治民之方。
    自爱不自贵珍重自己，却不自以为高人一等。谓珍爱自身、守其真而不自矜尊贵。“自贵”即自高自大、以己为贵。王弼本作“自爱不自贵”。王弼注：“自爱，则无自贵也。”陈鼓应译“爱惜自身而不自显高贵”。与第七十二章上文“自知不自见”并列，构成一组对治之方。河上公从治身解“自爱”为爱惜精气，不“自贵”即不矜高位，偏于养生；王弼以“无”为本，谓“自贵”是名分之执，与自然之分相违；郭象“独化”说可通——各适其性即自爱，强分高下即自贵。儒家荀子“君子之学以美其身”亦重自爱，但以礼义为准的，与老子“不贵”的取向有别。
    去彼取此舍掉“自见”“自贵”，选取“自知”“自爱”。本章结句，谓圣人有所取舍：去“自见”“自贵”之弊，取“自知”“自爱”之实。此语亦见于第十二章、第三十八章，为《老子》中反复出现的抉择句式。王弼本作“故去彼取此”。王弼注多就“本末”立说，去末取本；陈鼓应译为“所以舍弃自见自贵，而保持自知自爱”。楼宇烈《王弼集校释》指出此句式在王弼注中常涵“崇本息末”之义。王弼以“崇本息末”解“去彼取此”，彼为末、此为本文；成玄英重玄学则解为遣执而不滞于遣，取舍亦不可执；王夫之《老子衍》从“气化”与“日新”立论，谓取舍非一次之定，而在随时之当，与王弼的静态本末说有别；海德格尔论“遮蔽”与“解蔽”的往返，或可与“去彼取此”的持续抉择相参，但其存在论境域与老子的治道语境不同。

    大威

    L0百姓一旦不再害怕威压，更大的祸乱或灾殃就会到来。
    L1指百姓对威压失去畏惧后所招致的更大祸患，历代注家多解为“祸乱之大者”，亦有人解为“天威”“刑威之极”。
    L2王弼注：“威不能制，则大威至矣。”以“大威”为威之极致、威穷而反；河上公以“大威”为“祸罚”；成玄英疏以重玄义解为“大威之至，莫过于死”。陈鼓应译为“可怕的祸乱就要到来”。
    L3河上公、道教养生一路把“大威”读作身国同构中的灾殃，偏重治身；王夫之《老子衍》从气化治乱着眼，谓威穷则民散、大乱随之，重在社会政治之势；韩非一系则会把“大威”理解为君权失驭后的刑赏失序，与老子“不尚威”的告诫形成张力。

    无狎其所居

    L0不要逼迫百姓的居所，使他们住得局促不安。
    L1“狎”通“狭”，作动词用，谓使之狭窄、逼迫。此句意为统治者不应侵扰、压缩百姓的生存居所。
    L2帛书乙本作“毋狎其所居”，王弼本作“无狎其所居”。王弼注：“狎，近也。”一说“狎”为“狭”之借字，河上公本即作“狭”。陈鼓应取“狭”义，译“不要逼迫人民的居所”。
    L3河上公以“所居”为身中之神室，主张治身者不使精神局促，是养生化的读法；王弼以“无”为本，将“所居”解为万物自得之所，反对以有为侵夺其自然之分；郭象“独化”说可相呼应——各安其性分，不须外力安排其居处。

    无厌其所生

    L0不要压榨百姓赖以活命的生活来源。
    L1“厌”读作“压”，意为压迫、厌弃。此句谓统治者不应摧残、堵塞百姓的生存之道。
    L2王弼本作“无厌其所生”，王弼注：“厌，塞也。”河上公注“厌”为“压”。陈鼓应译“不要压榨人民的生产”，并引“厌”与“压”古通之说。
    L3河上公从治身立论，谓“所生”即精气，厌之则神疲，属养生内修一路；王弼以“生”为自然之性分，厌塞之则违“无为之本”；儒家孟子“制民之产”与“无恒产者无恒心”之说与此章“不厌所生”在治理关怀上相通，但孟子立足仁义之政，老子立足不扰之政，进路不同。

    自知不自见

    L0有自知之明，却不自我炫耀、不处处表现自己。
    L1谓人应有内在的明察而不外露张扬。“自见”读作“自现”，即自我表现、自炫。
    L2王弼本作“是以圣人自知不自见”。王弼注：“自知，则无自见也。”陈鼓应译“有自知之明而不自我炫耀”。此句与第二十四章“自见者不明”互文。
    L3王弼以“无”为本，认为“自见”是执有之迹，“自知”则返本；成玄英以重玄双遣解之，既不执自见，亦不滞自知，遣之又遣；庄子“至人无己”与“吾丧我”可相参照，但庄子落实于齐物逍遥，老子此章落在治民之方。

    自爱不自贵

    L0珍重自己，却不自以为高人一等。
    L1谓珍爱自身、守其真而不自矜尊贵。“自贵”即自高自大、以己为贵。
    L2王弼本作“自爱不自贵”。王弼注：“自爱，则无自贵也。”陈鼓应译“爱惜自身而不自显高贵”。与第七十二章上文“自知不自见”并列，构成一组对治之方。
    L3河上公从治身解“自爱”为爱惜精气，不“自贵”即不矜高位，偏于养生；王弼以“无”为本，谓“自贵”是名分之执，与自然之分相违；郭象“独化”说可通——各适其性即自爱，强分高下即自贵。儒家荀子“君子之学以美其身”亦重自爱，但以礼义为准的，与老子“不贵”的取向有别。

    去彼取此

    L0舍掉“自见”“自贵”，选取“自知”“自爱”。
    L1本章结句，谓圣人有所取舍：去“自见”“自贵”之弊，取“自知”“自爱”之实。此语亦见于第十二章、第三十八章，为《老子》中反复出现的抉择句式。
    L2王弼本作“故去彼取此”。王弼注多就“本末”立说，去末取本；陈鼓应译为“所以舍弃自见自贵，而保持自知自爱”。楼宇烈《王弼集校释》指出此句式在王弼注中常涵“崇本息末”之义。
    L3王弼以“崇本息末”解“去彼取此”，彼为末、此为本文；成玄英重玄学则解为遣执而不滞于遣，取舍亦不可执；王夫之《老子衍》从“气化”与“日新”立论，谓取舍非一次之定，而在随时之当，与王弼的静态本末说有别；海德格尔论“遮蔽”与“解蔽”的往返，或可与“去彼取此”的持续抉择相参，但其存在论境域与老子的治道语境不同。
