📜 原文

昔之得一者，天得一以清，地得一以宁，神得一以灵，谷得一以盈，万物得一以生，侯王得一以为天下正。其致之，天无以清将恐裂，地无以宁将恐废，神无以灵将恐歇，谷无以盈将恐竭，万物无以生将恐灭，侯王无以贵高将恐蹶。故贵以贱为本，高以下为基。是以侯王自称孤、寡、不谷。此非以贱为本邪？非乎？故致誉无誉，不欲琭琭如玉，珞珞如石。

📖 四步导读

《第 39 章》四步导读


①书概览（5 分钟，建立全貌）

本章说：天清、地宁、神灵、谷盈、万物生、侯王正，全靠“得一”——守住“道”这个根本。反过来，一旦失“一”，天要裂、地要废、神要歇、谷要竭、万物要灭、侯王要栽。由此老子推出两句政治箴言：“贵以贱为本，高以下为基”，并夸侯王自称“孤、寡、不谷”正是这个道理。最后落到人格理想：最高的荣誉是不求荣誉，不做光鲜美玉，宁做质朴坚石。有趣之处在于：它把宇宙论和政治伦理用同一个“一”串起来。

②多问题意识关联

如果一座高楼的地基被悄悄抽走，楼上的人多久才会察觉？
如果所有头衔、荣誉突然被收回，你还剩下什么可称之为“你”？
如果一个领导者不再需要“下面的人”，他还能维持“上面”吗？

③其他作者观点碰撞

荀子：主张“礼”与“群居和一”，同样重视秩序赖以成立的根本，但他把根本落在人为的礼义制度，而非老子那个不可名的“一”。
韩非：读“贵以贱为本”会点头——但他从中推出的是法与势的操控术，君主自谦只是姿态，骨子里是“术”。
涂尔干：社会靠集体欢腾与象征维系整合，与老子“万物得一以生”可对照：他说的“一”是社会的道德共识，不是宇宙本源。
维特根斯坦：会追问“得一”这个词在什么语言游戏里才有意义——老子的话像格言，其力量来自用法而非可证伪的命题。

④精读推荐（小白怎么读这章）

（1）第一遍（速览）：三个关注点——①六个“得一以……”的排比：天、地、神、谷、万物、侯王各得什么属性；②紧接的六个“将恐……”反转句：一一对应地写出失“一”的后果；③末尾从宇宙论拐向政治和人格的两处转折。

>

（2）第二遍（细抠）：必看两个论证——①“故贵以贱为本，高以下为基”如何从前面天地的排比中被推出来：请注意老子是把“侯王”放进天、地、神、谷、万物的同一序列里，贵贱关系因此被说成一种存在论结构，而不只是道德劝告；②“侯王自称孤、寡、不谷”这个例证：老子用反问“此非以贱为本邪？非乎？”来逼读者自己确认，这里的论证靠的反问式认同，而非演绎。

>

（3）第三遍（思辨）：值得追问的开放问题——“致誉无誉”是否自相矛盾？如果最高的荣誉就是不要荣誉，那么“不要荣誉”本身会不会变成另一种更隐蔽的求誉？老子用“琭琭如玉”对“珞珞如石”作结，这个比喻是在消解荣誉，还是在悄悄重建一种“以不争为争”的更高荣誉？

📝 结构化笔记

章节主旨：本章从“得一”正面阐明道作为万物存在与正常属性的根据，又以“失一”的后果反证之，继而引出“贵以贱为本，高以下为基”的政治伦理，并收束于“致誉无誉”的谦卑人格理想。

📌 核心命题

  1. 天、地、神、谷、万物、侯王都因“得一”而具有各自属性：清、宁、灵、盈、生、正。
  2. 失去“一”则天裂、地废、神歇、谷竭、万物灭、侯王蹶。
  3. 贵以贱为本，高以下为基。
  4. 侯王自称孤、寡、不谷，体现以贱为本。
  5. 最高的荣誉是无誉，不追求琭琭如玉，而愿珞珞如石。

🔑 关键论据

  1. 天得一以清，地得一以宁，神得一以灵，谷得一以盈，万物得一以生，侯王得一以为天下正。
  2. 其致之：天无以清将恐裂，地无以宁将恐废，神无以灵将恐歇，谷无以盈将恐竭，万物无以生将恐灭，侯王无以贵高将恐蹶。
  3. 故贵以贱为本，高以下为基。
  4. 是以侯王自称孤、寡、不谷。此非以贱为本邪？非乎？
  5. 故致誉无誉，不欲琭琭如玉，珞珞如石。

    得一天、地、神、谷、万物、侯王都是因为守住了那个最根本的“一”，才成其为天、地、神、谷、万物、侯王；丢了“一”就会崩坏。“一”在《老子》中常被用作“道”的代称。“得一”指万物从道那里获得自身存在的根据，从而能显现其德性（如天得之以清、地得之以宁）。第39章以“昔之得一者”起首，列举天、地、神、谷、万物、侯王六者，说明“一”是它们各自成立的条件；随后以“其致之”转折，指出若失“一”则天裂、地废、神歇、谷竭、万物灭、侯王蹶，从正反两面确立“道”作为存在根据的绝对性。王弼注：“一，数之始而物之极也。”以“一”为万物之极、无为之本；“昔之得一者”即“各以其一得”其性。河上公注则把“一”解为“道之所生，太和之精气”，倾向养生与元气论。成玄英《道德经义疏》以重玄双遣解之，谓“一”亦不可执。陈鼓应认为此章“一”即“道”的别名，“得一”即“得道”，是老子对道与万物关系的具体化表达；刘笑敢指出“得一”体现老子“以道为万物存在依据”的生成论结构。王弼以“无”为本，认为“一”是数的起点也是万物的极致，万物所以能成其为自己，正因禀受了这个“无”之本，故主张“崇本息末”；郭象注《庄》主张“独化”，认为万物“块然自生”“无待而自足”，不需要一个更高的“一”作根据，与老子“得一”的生成论结构形成对立；河上公与道教内丹传统则把“一”读作“气”“精”“神”，将“得一”转化为守一存神的修炼工夫，如《太平经》“守一”之法；苏辙《老子解》以“理”言“一”，谓万物各得其一以为其性，近于理学化的解读；海德格尔论“根据”（Grund）时说，存在者之存在总已在其根据中被给予，与老子“得一”所言“存在者因道而成立”有结构上的可比较性，但海氏拒绝把根据再实体化为一个“最高存在者”，恰与王弼“以无为本”而非“以一为物”的取向相通。
    孤、寡、不谷君王自称“孤家”“寡人”“不谷”，不是谦虚客套，而是表示自己站在最低、最贱的位置上，因为“贵以贱为本，高以下为基”。“孤”“寡”“不谷”皆为古代君主自谦之称。“孤”谓孤独无德，“寡”谓寡德，“不谷”即“不善”（谷，善也）。《老子》第39章云：“故贵以贱为本，高以下为基。是以侯王自称孤、寡、不谷。此非以贱为本邪？非乎？”老子指出侯王以此自称，正是“以贱为本”的体现，并以“故致数舆无舆”（一说“至誉无誉”）说明最高的称誉反倒不需称誉，由此批评世俗对“贵”“高”的执着。王弼注：“可得而名，故曰孤、寡、不谷也。”谓侯王处尊而自称贱，是“以贱为本”的名言层面的体现；河上公注把“孤寡”解为“孤寡孤独”之人，强调人君当哀怜孤弱；成玄英则从重玄角度说“非誉非不誉”，连“以贱为本”亦不执。陈鼓应释此章为老子对侯王的告诫，指出“贵以贱为本”是老子辩证法的具体运用，与“反者道之动”一脉相承；楼宇烈强调此节体现老子“处下”“守柔”的政治伦理。儒家对“名”的态度与老子形成对照：孔子主张“必也正名乎”，荀子《正名》篇论“名定而实辨”，认为名分秩序是社会治理的基础，而老子恰恰认为侯王自贬其名（孤、寡、不谷）才合于道，二者在“名”的功能上取向相反；韩非《解老》《喻老》则以“术”解此章，把“贵以贱为本”读作君主治国必须“以贱为基”、借卑下之姿控驭臣下的权术，与老子的本体论意涵分道；庄子“齐物”认为贵贱之分本无定准，“以道观之，物无贵贱”，把老子的“以贱为本”推向消解贵贱对待的层面；王夫之《老子衍》以“气化”言道，认为贵贱高下只是气之聚散升降的相对名相，不可以为实体。西方方面，维特根斯坦论语言中的“界限”时指出，某些位置（如“最低”）只有在整套比较系统内才有意义，侯王自称“孤寡”正是通过在名号系统内自我降格来确立其位，这与老子“高以下为基”的辩证结构可相互照明。

    L3王弼以“无”为本，认为“一”是数的起点也是万物的极致，万物所以能成其为自己，正因禀受了这个“无”之本，故主张“崇本息末”；郭象注《庄》主张“独化”，认为万物“块然自生”“无待而自足”，不需要一个更高的“一”作根据，与老子“得一”的生成论结构形成对立；河上公与道教内丹传统则把“一”读作“气”“精”“神”，将“得一”转化为守一存神的修炼工夫，如《太平经》“守一”之法；苏辙《老子解》以“理”言“一”，谓万物各得其一以为其性，近于理学化的解读；海德格尔论“根据”（Grund）时说，存在者之存在总已在其根据中被给予，与老子“得一”所言“存在者因道而成立”有结构上的可比较性，但海氏拒绝把根据再实体化为一个“最高存在者”，恰与王弼“以无为本”而非“以一为物”的取向相通。

    孤、寡、不谷

    L0君王自称“孤家”“寡人”“不谷”，不是谦虚客套，而是表示自己站在最低、最贱的位置上，因为“贵以贱为本，高以下为基”。
    L1“孤”“寡”“不谷”皆为古代君主自谦之称。“孤”谓孤独无德，“寡”谓寡德，“不谷”即“不善”（谷，善也）。《老子》第39章云：“故贵以贱为本，高以下为基。是以侯王自称孤、寡、不谷。此非以贱为本邪？非乎？”老子指出侯王以此自称，正是“以贱为本”的体现，并以“故致数舆无舆”（一说“至誉无誉”）说明最高的称誉反倒不需称誉，由此批评世俗对“贵”“高”的执着。
    L2王弼注：“可得而名，故曰孤、寡、不谷也。”谓侯王处尊而自称贱，是“以贱为本”的名言层面的体现；河上公注把“孤寡”解为“孤寡孤独”之人，强调人君当哀怜孤弱；成玄英则从重玄角度说“非誉非不誉”，连“以贱为本”亦不执。陈鼓应释此章为老子对侯王的告诫，指出“贵以贱为本”是老子辩证法的具体运用，与“反者道之动”一脉相承；楼宇烈强调此节体现老子“处下”“守柔”的政治伦理。
    L3儒家对“名”的态度与老子形成对照：孔子主张“必也正名乎”，荀子《正名》篇论“名定而实辨”，认为名分秩序是社会治理的基础，而老子恰恰认为侯王自贬其名（孤、寡、不谷）才合于道，二者在“名”的功能上取向相反；韩非《解老》《喻老》则以“术”解此章，把“贵以贱为本”读作君主治国必须“以贱为基”、借卑下之姿控驭臣下的权术，与老子的本体论意涵分道；庄子“齐物”认为贵贱之分本无定准，“以道观之，物无贵贱”，把老子的“以贱为本”推向消解贵贱对待的层面；王夫之《老子衍》以“气化”言道，认为贵贱高下只是气之聚散升降的相对名相，不可以为实体。西方方面，维特根斯坦论语言中的“界限”时指出，某些位置（如“最低”）只有在整套比较系统内才有意义，侯王自称“孤寡”正是通过在名号系统内自我降格来确立其位，这与老子“高以下为基”的辩证结构可相互照明。
