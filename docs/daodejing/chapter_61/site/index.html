📜 原文

大国者下流，天下之交，天下之牝，牝常以静胜牡，以静为下。故大国以下小国，则取小国；小国以下大国，则取大国。故或下以取，或下而取。大国不过欲兼畜人，小国不过欲入事人。夫两者各得其所欲，大者宜为下。

📖 四步导读

《第 61 章》四步导读


①书概览（5 分钟，建立全貌）

这章讲大国与小国怎么相处。老子打了个比方：大国要像江河下游，百川汇注，安静处下。他用“牝常以静胜牡”说明安静谦下反而占优。核心结论是：大国对小国谦下就能取得小国，小国对大国谦下就能取得大国——双方都谦下，但“大者宜为下”。有趣之处在于，老子把国际关系讲成了一种“以退为进”的力学：谁更大，谁更该先低头。最重要收获：谦下不是道德姿态，而是一种结构性的智慧——位置越高，越要往下处。

②多问题意识关联

1. 如果你是大国决策者，面对小国，你会先展示力量还是先主动谦下？为什么？
2. 如果“谦下”是一种策略而非品德，那小国的“下”和大国的“下”有什么本质不同？
3. 如果双方都谦下、各得所欲，老子为什么还要补一句“大者宜为下”？谁多让一步？

③其他作者观点碰撞

- 荀子：主张“以德兼人”，认为兼并别国要靠德行感化而非强力胁迫（《议兵》篇），与老子“大国以下小国则取小国”有相通处，但荀子更强调礼义制度的建构，不止于姿态上的“下”。
- 韩非：法家视角看国际关系，认为“下”只是权术手段之一，本质是计算利害强弱；《韩非子》中反复讲君臣父子皆以计合，谦下若不能带来实际利益便无意义——这与老子把“下”讲成近乎自然的道理形成张力。
- 福柯：权力关系无处不在，“谦下”本身也是一种权力技术——通过自我克制、自我降格来生产对方的顺从与依附，所谓“取”不过是权力毛细血管中的一种运作方式。
- 罗素：在《权力论》中把权力欲视为政治的核心动力，若以此看老子，大国的“下”可理解为一种间接权力策略：不直接压服，而通过让利与包容来扩大影响力。

④精读推荐（小白怎么读这章）

（1）第一遍（速览）：三个关注点
- 注意“下流”不是贬义：老子用它指江河下游，百川汇聚之处——位置最低，反而容纳最多。
- 注意“牝常以静胜牡”这个性别隐喻：老子用雌雄、静动来讲优劣，不是道德褒贬，而是结构分析。
- 注意最后一句“大者宜为下”：全章落脚点不在小国，而在大国——越强越要主动处下。

>

（2）第二遍（细抠）：两个必看的论证
- “故大国以下小国，则取小国；小国以下大国，则取大国。”——这是双向对称结构：双方都用“下”来“取”，但“取”的含义不同。大国的“取”是取得小国的依附，小国的“取”是取得大国的容纳。要看清“取”字前后的主客关系。
- “故或下以取，或下而取。”——这句最容易被略过，其实是全章的关节：一种“下”是主动去取得（下以取），一种“下”是因谦下而被取得（下而取）。老子把两种“下”的结果区分得很清楚，不是笼统讲“谦下就好”。

>

（3）第三遍（思辨）：一个该追问的开放问题
- “大者宜为下”究竟是道德劝告，还是策略计算？如果大国谦下只是为了“兼畜人”——扩大自己的容纳范围与影响力——那这种“下”还算是真正的谦下吗？老子没有正面回答，但这正是读者该自己追问的地方：当“处下”本身成为一种“取”的手段，谦下与权谋的边界在哪里？

📝 结构化笔记

章节主旨：本章论述大国与小国的相处之道，提出大国应像居于下游一样谦下包容，以静处下，从而使大国兼畜、小国入事，双方各得所欲。

📌 核心命题

  1. 大国应当像居于下游一样处下，成为天下交汇之处。
  2. 牝常以静胜牡，说明安静和处下具有优势。
  3. 大国对小国谦下，就能取得小国；小国对大国谦下，就能取得大国。
  4. 谦下有两种结果：以谦下取得，或因谦下而被取得。
  5. 大国不过想兼畜人，小国不过想入事人，两者各得所欲时，大国更应处下。

🔑 关键论据

  1. 大国者下流，天下之交，天下之牝，牝常以静胜牡，以静为下。
  2. 故大国以下小国，则取小国；小国以下大国，则取大国。
  3. 故或下以取，或下而取。
  4. 大国不过欲兼畜人，小国不过欲入事人。
  5. 夫两者各得其所欲，大者宜为下。

💡 新概念

下流
这里指居于下游，比喻大国应处在谦下的位置。
牝
雌性，文中用来喻指安静处下的一方。
牡
雄性，文中与牝相对。
以静为下
以安静保持谦下。
兼畜人
兼并畜养他人，指大国容纳、养护小国。
入事人
加入并事奉他人，指小国依附、事奉大国。

    牝雌性、母性，代表安静柔顺的一方。雌性鸟兽；老子用以象征静、柔、下位，与“牡”相对。《老子》“天下之牝”“牝常以静胜牡”；王弼注“牝，雌也”，以“静”释牝，核心术语为“静”“胜”“下”。王弼注“雄躁动贪欲，雌常以静，故能胜雄”，以贵无主静解；河上公注以雌柔为养生治国之德；陈鼓应说牝象征雌柔、静定；成玄英重玄学可解为遣执归静，但不是直接注此句。
    牡雄性、公性，代表躁动主动的一方。雄性鸟兽，与“牝”相对；老子用以指躁动、主动、争胜的一方。《老子》“牝常以静胜牡”；王弼注以“雄躁动贪欲”释牡，核心术语为“躁”“动”“贪欲”。王弼以“静”为反本，故牝以静胜牡；河上公从养生说牡为躁动耗散、牝为安静自守；陈鼓应指出老子不是贬斥雄性，而是以雌静喻谦下策略；韩非《解老》重静以少费，可作对照，但不直接释此章。
    以静为下用安静、谦下的方式处理关系。以静定自处，并以此表示谦下；老子认为静能胜动、下能取上。《老子》“牝常以静胜牡，以静为下”；王弼注以“静”为反本、以“下”为不争，核心术语为“静”“下”“胜”。王弼贵无主静，认为静是动的根本，故“以静为下”；河上公从养生治国说清静自守则能下人；苏辙《老子解》以静故能下、下故能取；陈鼓应指出这是老子“柔弱胜刚强”在处理大国小国关系上的应用。
    兼畜人包容、养护别人，把别国纳入自己的照顾范围。兼有并畜养他人；在大国语境中指大国包容、养护小国。《老子》“大国不过欲兼畜人”；王弼注以大国谦下畜小国释之，核心术语为“兼”“畜”“下”。王弼以政治谦下解大国欲兼畜小国；河上公从治国养生说“畜养”百姓小国；苏辙《老子解》说大国之欲不过兼畜小国；陈鼓应译为大国不过想包容养护小国；刘笑敢《老子古今》关注“兼畜”与“入事”的对等交换结构。
    入事人加入并侍奉别人，小国依附大国。进入并事奉他人；在小国语境中指小国谦下事奉大国。《老子》“小国不过欲入事人”；王弼注以小国下大国、入事以自存释之，核心术语为“事”“下”“取”。王弼以谦下外交解小国入事大国；河上公从治国说小国下大国以求安；苏辙说小国不过入事大国；陈鼓应译为小国不过想事奉大国；刘笑敢指出老子在大国小国之间设定“各得所欲”的互惠，而非单方屈服。
