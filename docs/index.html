把书拆成
能被读懂的结构

一本 PDF 或纯文本的书，自动拆成章节 → 结构化笔记 → 知识图谱 → 多难度术语表。 每章一个网页，双击就能读，手机也适配。

看《道德经》81 章示例 → GitHub 源码

为什么做这个

读一本硬书，真正卡住的往往不是字句，而是三件事：不知道这章在全书里处在什么位置、 抓不住作者的论证链条、概念和概念之间连不起来。

摘要有用，但它把结构磨平了。所以这里做的不是「压缩」，而是「还原结构」—— 让你看见命题、论据、案例、概念各自在哪里，以及它们怎么连。

一条流水线，五步

  1. 拆PDF 按页抽文字与插图；纯文本按章切分。
  2. 记逐页抽取核心命题、关键论据、案例、新概念、跨章线索。
  3. 连生成 Mermaid 知识图谱：命题、概念、案例、人物之间的支撑与关联。
  4. 译每个概念给 L0 白话 / L1 教材 / L2 学术 / L3 思想史 四层。
  5. 读章节页：原文置顶 + 四步导读 + 图谱 + 苏格拉底追问 + 术语表。

跑一本书要多久

《道德经》81 章

4 路并行，约 17 分钟。2000+ 条结构化笔记。

《世界的逻辑》14 章 / 550 页

顺序跑约 2.5 小时。1900+ 条笔记、490+ 图谱节点。

关于示例内容： 《道德经》原文属公有领域（王弼通行本），可直接公开。 章节解析部分由 AI 辅助生成，属于加工产物，请以原文为准。 版权期内的书（如现代出版物）建议仅个人使用。

git clone <this-repo>

python 13_run_parallel.py --book daodejing --workers 4
