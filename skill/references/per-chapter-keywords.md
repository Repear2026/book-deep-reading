# 每章关键词清单（章节主题指纹）

在 `scripts/lib/review.py` 里 `CHAPTER_KEYWORDS` 字典定义了每章应出现的关键词，用于评估模型产出的"内容覆盖度"。

新增一本书时，应针对每章写 5-10 个主题词（中文），覆盖该章核心概念。

## 模板（哲学/通识方向）

```python
CHAPTER_KEYWORDS = {
    "01": ["主题A", "主题B", "人物C", "概念D", ...],
    "02": [...],
    ...
}
```

## 示例（马兆远《世界的逻辑》）

```python
CHAPTER_KEYWORDS = {
    "01": ["语言", "智人", "维特根斯坦", "尼安德特", "文字", "大规模合作", "基因"],
    "07": ["数学危机", "无理数", "贝克莱", "罗素", "集合论", "无穷", "公理"],
    "12": ["概率", "贝叶斯", "频率", "条件概率", "分布", "统计", "不确定性"],
    "13": ["量子", "叠加", "观察者", "互补", "玻尔", "海森堡", "量子逻辑"],
    ...
}
```

## 选词准则

1. **核心人物**（亚里士多德、哥德尔、贝叶斯）
2. **核心概念**（完备性、不确定性、迭代）
3. **关键术语**（公理化、统计推断）
4. **避免**：通用品词（"问题""分析""讨论"——任何章节都有，没区分度）

## 为什么需要关键词

- 模型有时候"假装"做了，但跑出来全是空话；关键词覆盖率能反映
- 90%+ 覆盖率 = 高质量产出；<40% 时 review 自动 WARN
- 关键词清单本身就是用户对"该章节应涵盖"的预期，对照 LLM 输出的覆盖度可发现问题章节

## 调覆盖率门槛

`scripts/lib/review.py` 默认 ≥40% 通过（WARN）。如果是技术类书，可以调 60%；如果是社科类，30% 也行（在 `review.py` 找 `coverage < 0.4` 那一行改）。
